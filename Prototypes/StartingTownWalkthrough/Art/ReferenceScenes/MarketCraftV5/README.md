# V5：完整三维市场街

用户最新明确要求：正常搭建更精致、细节更多、符合原著设定的模型，不再强求动画截图完全一致。V4 反投影路线已经否决并归档。V5 不包含图像像素坐标，不通过相机去扭曲建筑轮廓。

本轮制作两栋可进入的近景店屋及一段市场街。石造楼体、灰泥上层、拱形门窗、绿百叶、红瓦、遮棚及远端门桥/圆塔/穹顶沿用起始之城的建筑语言。两家具体店铺、功能、精确布局、楼层高度、背面和室内均为项目补全，不冒充原著指定商铺。托尔巴纳保留旧资产及独立地理位置；没有引入旧国王或中央高地城堡。

## 可编辑源与运行

- `StartingTown_Market_CraftV5.blend`：米制完整建筑、木作、棚布与陈设。
- `build_market.py`：街区组装、远景、原地理锚点、材质微表面与导出。
- `architecture.py`：独立砌石、实开门窗、拱券、窗框与百叶、花箱、瓦片屋面、带支撑的棚布、侧后墙与楼板。
- `interiors.py`：敞开木门、柜台、货架、受支撑商品、面袋、小烤炉与工具、店内碰撞。
- `textures/`：本地程序生成的石/木/灰泥微法线，GLB 内嵌。不使用参考动画图作为贴图。
- `shop_fittings.py`：未采用的代理初稿；主程序使用 `interiors.py`。

项目目录 `./Run.ps1` 默认进入 V5；`-Mode market-demo` 同义，`R` 回到街角展示机位，`O` 看整体，`WASD` 可进入两家店。`-Mode play` 或直接运行原 `main.tscn` 保留旧 HQ 默认清单。采集：`./Run.ps1 -Mode market-demo-capture -Revision manual`。

导出物：`assets/reference_scenes/StartingTown_Market_CraftV5.glb`、`market_craft_v5_manifest.json`。最终图和工程记录见 [V5 验证](../../../validation/market_craft_v5/README.md)。主程序保留两个城镇的原地理位置；当前具体街区尺寸是项目补全。

本轮只推进市场街正常三维模型，托尔巴纳尚未按新方式细化。楼上与屋顶是完整外部体量，没有实现上楼路径；两家一层可进入。烤炉、货架与商品是美术及碰撞资产，尚未接入生产/交易功能，不代表居民真实使用已经发生。

全局光照、Shader、后处理与雾保持原审模设置。新增材质微表面属于资产候选，不构成全局画风认可。旧存档、真实身份、Kimi 预算和预留未改；Kimi 调用 0，无提交或上传。
