# 托尔巴纳：完整三维模型 V5

2026-09-09 用户要求：另一个场景也按新版市场街方式正常搭建、更精致、更多细节，然后共同对齐画风。沿用用户上一轮裁决，不再按截图反投影变形或要求逐像素一致。

本目录包含可重新生成的 Blender 源脚本与 `Tolbana_Plaza_CraftV5.blend`。`build_tolbana.py` 只读取旧 HQ 的托尔巴纳场景作为既有远景/地面上下文，替换四栋临广场建筑、大树、草丛、喷泉和座椅花坛。旧源未覆盖。底层几何复用 `../MarketCraftV5/architecture.py`、`interiors.py` 和 `../build_reference_scenes_hq.py`，无单机位投影依赖。

- 四栋住宅/旅店有完整侧后墙、门窗洞、窗扇、石框、花箱、檐口、瓦片屋面与烟囱。旅店首层有可进入的餐厅、桌椅、盘碗面包、吧台和炉台；楼上和其余住宅未做可游玩室内。
- 大树有根、树干纹理几何、分枝、分组叶簇；草丛有疏密分区。当前草地基底仍平涂，花坛叶形仍简化，需在画风阶段配合纹理/着色调整。
- 三级喷泉有连续内外石剖面、独立池壁石、雕槽、池内排水口、薄片落水和环形铺装。水当前仍为静态、不透明的表现候选，未实现流体或最终水 Shader。
- 两把长凳采用独立坐板、靠背、连续扶手支架和连接件，坐高为离地 0.46 m；五组木花坛避开座椅。

位置保持在第一层托尔巴纳：Godot `(0,0,-7670)`，第一层坐标 `(0,2900)`；市场街保留其独立起始之城位置。广场树、喷泉、浅色住宅和红瓦为动画语言参考；精确建筑位置、尺寸、旅店用途及内部陈设是项目补全。没有官方完整城市测绘，不声称这些是原著唯一布局。

启动：在项目目录执行 `./Run.ps1 -Mode tolbana-demo`，按 `4`/`5` 切换新版市场街/托尔巴纳。Godot 直接运行项目也加载两处 V5。`./Run.ps1 -Mode tolbana-demo-capture -Revision manual` 生成真实多机位和行走证据。
