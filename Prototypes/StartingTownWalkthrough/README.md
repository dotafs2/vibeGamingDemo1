## 启动

用 Godot 打开 `project.godot` 并运行；本机也可执行 `./Run.ps1`。脚本优先使用 PATH 中的 godot，再尝试本轮下载的用户缓存副本。其他电脑可用 `./Run.ps1 -GodotPath '完整引擎路径'`。脚本不安装软件，不启动后台服务。

本机实测 Godot **4.7.2 stable mono official**、Windows、RTX 4060、GL Compatibility。项目仅使用 GDScript；没有 C# 编译依赖。Godot 下载自官方跳转，Windows 签名验证为 Valid / Prehensile Tales B.V.。引擎及其 ZIP 位于用户缓存，不作为项目美术或源码打包。

- WASD 行走，点击窗口后鼠标转向；Shift 快走，空格跳跃，Esc 释放鼠标。
- 1 广场、2 市场街、3 北城门；T 切换俯瞰。
- F5 柔和明暗、F6 分层明暗、F7 同一草模与调色板的标准 PBR 参考。
- `./Run.ps1 -Mode validate`：约 8 秒的无窗口空间检查，成功后更新局部导航资源和 JSON 证据。
- `./Run.ps1 -Mode capture`：数秒渲染并保存截图，然后自动退出。

## 本轮通过的检查

见 [原始空间验证快照](validation/spatial_before_reference_scenes.json)：GLB 运行时导入、四处地面射线、拱廊侧向阻挡、导航同步、广场至市场街路径、角色实际穿过西拱廊、唯一对象名称、导航保存均通过。789 个网格实例、19,232 个三角形只是规模记录，不代表功能完成。

角色以真实 `CharacterBody3D` 运动约 35 m，从 x=-74 走到约 -109 m；导航查询得到 49 个路径点并抵达市场目标附近。**验证的是局部空间可达，不是 NPC 已按整条路径行走或整城导航已验收。** 局部导航只覆盖广场西侧与首段市场街；几何变更后需要重新烘焙。

修复过的失败：导航资源烘焙完成后，导航地图和区域仍需要同步。初版仅等两帧或等待全局地图非零版本号，会在区域尚未注册时查询到空路径。现在有界等待地图版本推进且区域边界就绪。保留此说明，不能把早期失败描述为从未发生。

见 [render_validation.json](validation/render_validation.json) 与 `validation/view_*_style_*.png`：已在真实渲染器中生成广场、市场街三种参考，以及俯瞰图。截图时锁定输入与位置，使不同明暗模式使用同一视点。F7 是基础 PBR 草模，没有照片级纹理、人物、动画或高质量间接光，**不能据此比较成熟三渲二与成熟写实作品的受欢迎程度**。
