# 未对齐原图的原因核对

2026-09-09，用户指出对照图中的模型乃至位置都未对齐，要求先分析原因。本轮只核对代码、现有证据及用户附图，未改模型、相机或渲染，也未启动引擎、Blender、浏览器或代理。

## 核对结论

主要问题是制作与验收流程没有把“按动画画面还原”落实为可检查的几何约束。当前代码按人工指定的尺寸与位置组合建筑、地标和陈设，缺少与参考图对应的测量点、透视匹配和轮廓比较记录。增加了局部几何细节，但并未先保证整体构图成立。不能据此归因于 Blender 或引擎能力不足，也不能把缺少官方完整地图作为可见画面未对齐的理由。
