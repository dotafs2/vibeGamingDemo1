## 助手判断：待用户裁决

当前结果尚未达到用户要求的动画还原标准。上一版主要增加了窗框、瓦片、石块、叶片等几何细节，但这没有充分修正参照原图的比例、轮廓和细节分布。“HQ”是资产版本名称，不等于画面质量已经通过验收。

1. **市场的光色与明暗组织。** 动画右侧有清楚的青蓝背光，左侧遮棚、墙面和地面带暖光及局部反射色；门洞与摊位内侧较深，前后层次明确。实机整体灰黄，墙地同色，大片阴影比较单一，明亮铺地显得近乎发白。应联合调整固有色、天空补光、方向光与色调映射；一键增加饱和度不能替代这些关系。
2. **环境材质。** 动画墙面与石板的变化连续且不规则，材质和距离决定细节强弱。实机颜色变化多来自重复石块的离散色差，面内较平，近远都清楚，呈现陈列模型感。建议采用尺度一致的绘画感底色、受控粗糙度及局部痕迹；避免只添加均匀噪点或继续细分全部砖石。
3. **托尔巴纳植被和地标。** 动画树冠低垂、浓密，有大块亮叶和深色内部；实机裸露树干与上挑分枝过长，细叶和草叶呈重复碎点。树冠轮廓、分枝、灌木体量与草地边缘需改资产；分组法线与叶片着色负责整体受光。喷泉碗盘、立柱和出水形态也不同，当前水线接近细杆，应分别修改形体与水材质/动态表现。这些不能由全屏滤镜修复。
4. **布局与生活密度。** 市场的前景遮棚、陈设、人物遮挡密度不足，门桥、穹顶和塔楼关系仍偏离动画；托尔巴纳建筑剪影、道路和前景摊桌相对位置也未对齐。此类差异列为模型与摆放问题，不归罪于渲染。20 处同一桐人外观只是现阶段材质比较用实例，不代表目标居民构成。
5. **人物与空气感。** 桐人保留原纹理，但仍是基础 PBR 接入，后续应单独处理脸、头发和衣服的阴影。环境不宜统一套人物式明暗分段。参考中远景偏淡偏冷，可试少量距离雾/空气透视；没有证据支持先给整片街区加浓体积雾或强光柱。

助手建议的执行顺序为：先纠正醒目的形体与摆放误差，同时在两个固定视角调整光色关系；再做环境材质、植被和人物着色，最后按画面需要加入轻微空气透视。每一步保留真实引擎前后图，再检查近景、背光和移动镜头。这是建议，**尚未成为用户认可的全局渲染标准**。本轮停在展示与判断，不先实施上述美术调整。
