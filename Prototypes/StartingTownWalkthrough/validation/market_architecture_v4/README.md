## 本轮实际修改

- 左侧近墙、后退的中段立面、低矮远端店铺分别建模。重新设置每组高窗与下层洞口，补临街菱形窗格。窗洞是真实开孔，有浅进深、窗面与框件。
- 右侧远/近墙、前转角分开；修正补全侧墙覆盖原有窗口的问题。高窗不再被一整片封闭墙挡住。
- 棚布分别建屋面、前垂布、金色布幅与左上三角棚顶；分开白/绿/蓝棚布的轮廓和位置。
- 门桥使用与源图对应的开口及三个小孔，增加拱券和浅砌块起伏；圆塔分窄鼓座、外挑阳台、菱格栏板、拱廊、深色内围护和锥顶。远处为宽穹顶建筑叠加独立小穹顶塔。
- 补门桥右侧连接墙，保留可穿越门洞。原地理锚点 `(-163,0,-18)`、偏航 78°，以及动画机位均保留；不是把场景挪进独立摄影棚。

## 证据与验收边界

最终候选证据在 `r5/`：`reference.png` 正常实机、`architecture.png` 同机位隐藏测试人物、`motion_000/045/090.png` 连续移动镜头、`close.png`、`gate_detail.png`、`tower_detail.png` 和 `overview.png`。`comparison.html` 含动画/实机并排图、完整轮廓叠线、近景。右侧全部是 Godot 输出，没有以绘图修改模型或画面。

原图沿用 [Visual_References.md](../../Visual_References.md) 的市场街来源。2560×1600 文件上下黑边在比较页面中裁切，实际比较画幅 2560×1440。第三方托管、原生分辨率未核实的限制仍保留。没有将参考图作为游戏贴图或背景。

`capture.json` 中工程检查和 `review_result.json` 的视觉判断分开记录。89 组轮廓/特征点由实际 Camera3D 投影，但这只检查机位与导入，**不能证明描线一定准确，也不能单独证明模型还原通过**。用户最终视觉批准仍为 false；全局画风批准也为 false。

实际看图后的主代理判断：楼体分段、窗组位置、主要地标和遮挡已经具体修正，明显优于被拒绝的旧通用街景；还存在棚布形态偏规整、局部构件轮廓近似、石墙表面缺少动画的不规则层次等差异，不能记作完全复原。后续全局风格仍由用户看图裁决，不用调色掩盖几何偏差。

两名原有子代理分别检查过 V4 r1/r2 实机，指出窗洞被遮、右墙空白、门桥/圆塔层次问题。主代理随后完成 r4/r5 的修正；没有把早期代理意见冒充对最终版的通过。旧代理描线和模块因实际错误未被采用，保留在目录作失败证据。
