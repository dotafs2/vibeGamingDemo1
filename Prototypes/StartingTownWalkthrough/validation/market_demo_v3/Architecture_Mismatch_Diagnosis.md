# r10 建筑不一致：复核撤回与原因

2026-09-09。用户再次指出：不考虑人物重复，场景模型本身与动画不是同一套建筑，要求助手先解释原因。本轮重新实际查看 r10/comparison.png 并核对 assemble_market_demo.py 后，撤回此前“单机位模型/构图内部检查通过”的有效结论。保留两位代理曾给出通过意见这一历史事实；该意见不能作为下一阶段入口。

## 画面中仍存在的结构差异

- 左侧建筑的楼层分段、窗洞形状与排列、墙体转折、城垛节奏没有逐栋对应原图。代码使用同一 frontage 函数和等距窗口列表拼接不同长度的立面，只改变高度和位置。
- 右侧立面的窗洞高度、门窗组合、墙角与横向分层没有按参考建立对应关系。把整个墙面推远、降低屋顶只能改善遮挡，不能把现有建筑变成参考中的建筑。
- 后方穹顶群被实现成同一“圆筒鼓座＋椭圆顶盖＋一圈窗”的缩放重复。参考中的不同屋顶体量、附属塔、鼓座分段及彼此遮挡尚未被逐个还原。
- 棚布使用统一的曲面与下垂公式。对齐两处布边并没有约束整块棚面的覆盖范围、支撑关系、轮廓与搭接方式。
- 门桥与塔楼已有合法的三维结构，但其建筑分段、连接与整片轮廓仍缺完整对应约束。正确的门洞和塔尖位置不能证明整座地标被还原。

上述问题涉及模型和场景结构，不能归因于人物重复、光照不足、尚未加雾或材质未定稿。即使统一改成同一种灰色材质，这些差别仍会存在。

## 根因

1. **建模方法偏离用户要求。** 用户要求照着动画里的具体建筑还原；实际实现却使用通用建筑函数生成一套同类街景，再移动构件靠近参考。建筑结构的错误识别未在细化前解决。
2. **投影约束过少且不是整图约束。** 七个点包含人物头顶，建筑只约束了两处布边、三个门拱点和塔尖。立面窗序、穹顶完整轮廓、塔身分段、建筑连接均未覆盖。代码先指定相机和深度，再通过 ray_at 反推部分点的位置；没有完成从参考证据到整套场景比例、透视和遮挡的共同校准。
3. **细化投入落在未通过的大形上。** 砌块、倒角、接缝及大量网格只增加了当前造型的细节，未解决建筑本体的比例与结构对应。模型规模、导出次数和可运行性均不能证明还原质量。
4. **互审标准失效。** 六项检查大多检查是否有连拱、真实门洞、布面、圆顶、立面和前景层次；它们能判断组件是否成立，却不足以判断是不是参考中的同一套建筑。两位代理共享主代理的错误拆解，意见一致没有提供独立的整体建筑一致性证明。主代理不应以一致意见替代自己的实际视觉判断。
