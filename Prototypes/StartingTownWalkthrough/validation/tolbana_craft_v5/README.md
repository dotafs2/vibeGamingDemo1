## 画风讨论：尚未决定

主代理观察：墙面、草地、铺地大面积接近浅黄绿，材质变化仍少；树叶和草丛细碎，高光/透光/远景空气层次不足；桐人与环境的明暗表达仍有差异。喷泉水仍是**静态、不透明**的暂时表现，旅店室内缺少最终照明，远景仍有简化建筑和地形。以上都没有通过“模型已细化”自动解决。

建议先比较两种环境明暗方向：动画背景的柔和渐变/绘画纹理，或更鲜明的两三档硬边色阶。主代理倾向前者；这是建议，**不是用户选择**。收到方向后，两处用同一套材质/光照/后处理逐项试验；雾用来补远景层次，而不是掩盖近景材质问题。
