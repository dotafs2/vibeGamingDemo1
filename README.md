# 时间切换白盒 Demo

这是一个运行在浏览器中的纯 Three.js 2D 白盒玩法 Demo，用来验证一个最小概念：

> 玩家在过去做出的破坏，会在现代以连续、可见的方式产生结果，并且玩家可以随时无缝往返两个时代。

## 最小实现范围

- 网页运行，不制作完整客户端
- 纯 Three.js 渲染
- 固定二维正交视角
- 一个可控制的火柴人
- 一个可破坏的墙体
- 一个大盒子 Boss
- 两个时间状态：过去和现代
- 过去使用红色视觉表现
- 现代使用白色视觉表现
- `WASD` 控制上下左右移动
- `Q` 无缝切换过去和现代
- `Space` 发起攻击

## 核心体验

1. 玩家出生在现代。
2. 玩家按 `Q` 切换到红色的过去。
3. 玩家靠近墙体，连续攻击三次将墙打碎。
4. 玩家按 `Q` 回到白色的现代。
5. 现代的墙体从完整状态开始倒塌，直观表现历史已经被改变。
6. 墙体倒塌后，玩家可以穿过原本封闭的区域并攻击盒子 Boss。

## 技术实现

过去和现代不是两个需要重新加载的网页或场景。游戏使用一个共享场景和一个全局时间混合值，在切换时连续插值颜色、位置、旋转等属性。

需要跨时代变化的对象可以保存两套状态：

```js
{
  past: { position, rotation, color },
  present: { position, rotation, color }
}
```

墙体被摧毁会写入共享历史状态：

```js
worldState.wallDestroyed = true;
```

现代读取该历史状态并播放墙体倒塌，而不是简单隐藏或替换整个场景。这套结构之后可以扩展到门、桥、道路、NPC 和 Boss 阶段。

## 当前不做

- 美术资源和正式角色动画
- 地图编辑器与大型关卡
- 背包、装备、制作和建造
- 任务、对白和剧情系统
- 敌人 AI 与正式 Boss 战
- 存档、联网和 Steam 接入
- 第三个时代

这些功能只有在“过去改变现代”的最小体验验证成立之后才考虑加入。

## 本地运行

当前项目已包含本地 Three.js 文件，不依赖 CDN。使用任意静态文件服务器启动项目即可，例如：

```bash
python -m http.server 5173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:5173/
```

## MVP 验收标准

- 页面能够在本地浏览器正常打开
- 火柴人可以稳定地向四个方向移动
- 按 `Q` 时画面和对象状态连续过渡，没有页面刷新或场景加载
- 只有在过去攻击墙体才会改变历史
- 切回现代后能够清楚看到墙体倒塌
- 墙体倒塌后玩家可以通过原先封闭的位置
- 玩家能够靠近并攻击盒子 Boss
