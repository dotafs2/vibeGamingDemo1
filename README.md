# Level0 — 持续演进的 AI 世界

探索一个由 AI 居民自主生活、劳动、交易和建立关系的 SAO 式世界。世界事实与经历独立于模型，目标是让未来更好的模型能够继续提升同一个世界。

**当前是开发原型，尚不是可直接面向公众发行的游戏。** 13个持久角色身份中3人活跃；真实Kimi已发生修理交易、吃饭、休息与采集。Godot场景和UE社会模拟尚未完成整合。

## 开发者从这里开始

1. [当前状态与下一步](CURRENT_STATE.md)：另一台电脑的接手入口。
2. [主线协作规则](AGENTS.md)：token管理、模型分工和世界约束。
3. [近期交付路线](PROJECT_ROADMAP.md)：招募原型的可见验收。

近期交付：一个好看的小镇，5–10个自主生活的居民，可观察并干预真实事件，可下载体验并接入自己的模型。100名参与者和1万star是社区愿景，不是已达成指标。
