# SAO 第一层：资料基线与 MVP 校正

日期：2026-09-09。响应用户对“木匠与生活小镇是否符合 SAO”的质疑。本轮为第一批有出处的设定核查，不宣称搜集或读完全部小说。这里只记录简短事实摘要、出处和项目判断，不保存小说全文。

## 结论与适用范围

先建立第一层的设定基线，再决定角色、事件与建筑。生活职业可以存在，但不能用一般中世纪生活常识替代原作证据。木匠在本轮检索中未找到第一层的直接依据；这不证明原作不存在木匠，只表示目前不能把它当成已确认的首发角色。

《Progressive》第一层篇的官方公开章节明确涉及 NPC 锻冶、面包销售和提供住宿的 NPC 农家。因此三人闭环可以保留，但候选人物与事件应围绕第一层的补给、任务、装备、住宿和探索重新收敛。具体原创居民的名字、性格、经营动机与自主行动仍是项目扩展。

本文件校正同目录 `MIT_MVP_Blueprint.md` 的内容设计，不表示已迁移引擎、修改现有居民身份或重建世界存档。

## 1. 如何收集资料

| 层级 | 资料 | 用途和处理方式 |
|---|---|---|
| 小说依据 | 正篇相关卷、Progressive 第一层篇、作者相关短篇 | 规则、身份、地理、任务的主要依据；记录卷/篇/节、场景地点和故事时期 |
| 官方改编 | 动画、剧场版、官方设定介绍及美术资料 | 研究可见建筑、色彩、尺度关系；保留版本标签，与小说差异单列 |
| 游戏改编 | 各款 SAO 游戏的官方资料 | 可参考交互与视觉方案，不自动当作小说第一层事实 |
| 二手索引 | Wiki、带原文出处的考据 | 帮助定位原作；没有回到来源前标记“待核实” |
| 项目补全 | 原作未指定的路口、原创居民、实现细节 | 明确标注；不能被模型重复引用后升级为“官方事实” |
| 项目扩展 | 持久自主 NPC、跨模型延续、能力开发与自主建设 | 服务用户的长期目标，但不宣称原作已经定义了整套机制 |

“小说优先”是本项目的选用策略。正篇、Progressive、动画之间发生冲突时记录各版本，不能静默拼接。先核查第一层直接相关内容，其余楼层只在验证某项规则时定向查阅，避免一次收集所有分支却无法作出实施决定。

## 3. 尚不能直接作为原作事实的内容

- 第一层木匠的具体店铺、地位与玩法：待查；不能将“有木门”推断成“原作设定了木匠自主建设系统”。
- NPC 会因收入增长自行购买邻屋、扩建街区：项目扩展，不是本轮已核实规则。
- 首批每个 NPC 都有无限长的自主故事、能申请新增代码或模型：项目扩展。
- 起始之城每条街和每栋房屋的位置：本轮没有完整官方平面图；未确认处需要补全。
- 将精灵、怪物、任务或技能从其他楼层放进第一层：需要第一层证据或单独标记扩展。
- 把原作玩家当成普通原住民 NPC：身份错误。作者角色的已知经历不能直接分配给原创居民。
- 本轮未审定安全区的全部规则、战斗数值、任务刷新与物品供应机制；这些进入实际玩法之前需要定向补查。

## 4. 建议的设定文档与工作量

先以“第一层尚未攻略的时期”为设计窗口候选，具体起始时刻尚未定案。之后经历属于同一项目世界的持续历史，不每次迭代重新播放原作事件。

1. **区域表**：区域、相对方向、连接、地貌、地标、出处与未知细节。
2. **规则表**：Col、钱物归属、商店、技能、任务、装备、住宿、安全区与野外的适用规则；先实现少量已核实规则。
3. **居民表**：原住民 NPC / 玩家 / 怪物分开；职业依据、所属地点、本人知识与原创个性分开。
4. **视觉表**：小说描述对应具体动画/官方美术版本；列出可复用资产和必须改造的比例、服装、屋顶、材质。
5. **扩展表**：自主记忆、协商、建设和新能力安装分别标记为扩展，说明允许改变的范围。

每条记录至少有 `id / claim / source / continuity / floor / location / time_scope / evidence_status / implementation_status`。审核先查是否矛盾、是否越层和越时期，再考虑用途和实现成本；模型置信度不能代替出处。

NPC 只得到适用于其身份、地点与已知经历的资料片段。资料库中知道下一层 Boss 的人，不等于每个原住民都能预知它。世界规则与项目已开发能力由程序提供，不能让模型把设定提案说成已经发生。

## 5. 对最小 MVP 的具体调整

保留三名永久 NPC 与玩家、小场景、真实动作和保存恢复的规模。候选服务改为锻冶、面包销售、住宿，并在确定店铺地点之前核查或标为补全。S2、S3 中的具体场景在托尔巴纳，不能冒称起始之城的原文地址。

事件的题材方向改为：**出城前补给 → 一次有边界的野外活动 → 返回处理物品或强化装备 → 实际使用结果 → 记忆影响下一次选择**。第一批只选其中一笔完整交易和一次使用，不要求同时做齐三家店、全战斗与整座迷宫。

NPC 自主经营、协商与产生后续愿望属于本项目扩展。既保留用户希望他们能作出选择的目标，也明确这些选择机制不是小说中所有普通 NPC 都已具备的既定能力。以原作已存在的生活活动为落点，避免先把自主建城强设为每个人的目标。

居民真正提出缺失能力后，继续验证“需求—开发—安装原档—使用—第二人复用”；该长期闭环不取消。修改设定或升级模型也不能抹掉原档人物与历史。
