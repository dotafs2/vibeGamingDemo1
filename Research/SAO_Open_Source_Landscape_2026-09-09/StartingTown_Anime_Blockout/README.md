# 起始之城：动画依据与第一版轮廓

2026-09-09。用户要求按动画的起始之城轮廓开始搭建。当前交付是独立、可修改的几何研究，**不是官方完整地图，不是游戏实机，不包含 NPC 运行，也没有导入或覆盖现有 UE 世界**。

同日接续：这份几何研究现已由独立 [Godot 行走原型](../../../Prototypes/StartingTownWalkthrough/README.md) 实际导入并通过局部碰撞、导航和行走验证。下文“两张轮廓图非引擎画面”仍成立；真实引擎截图与后续验证位于该原型目录。未接入 NPC 或替换 UE 世界。

## 找到了什么

1. [TV 动画第一话官方剧照](https://www.swordart-online.net/aincrad/story/?id=ep01)：实看六张官网剧照，第三、四张能确认石砌拱廊、顶部栏杆与装饰柱，以及广场环绕的形体；第二张提供石砌巷道参考。
2. [中央广场俯视截图（第三方托管）](https://vignette.wikia.nocookie.net/swordartonline/images/0/07/Town_of_Beginnings%27_central_plaza_from_a_distance.png/revision/latest?cb=20140308064858)：实看后可辨认圆形铺地、中央细长钟塔、台阶和连续拱廊。拱廊形体、红色天空与官方第一话剧照可交叉核对。图像由 Wiki 索引取得，不是官方测绘图；本轮未逐帧核定时间码。
3. [市场街截图（第三方托管）](https://i.pinimg.com/originals/92/a3/a7/92a3a78f0b36febbef3abcb70f37ff7e.png)：画面自带第一层/起始之城字幕，能辨认石砌店面、遮棚、狭长街道和远处城门形体；精确镜头时间和街道方位待核。不能把其远景城门直接等同于最外圈北城门。
4. [Progressive 第一层篇第 3 节](https://dengekibunko.jp/novecomi/novel/16817330648099677277/16817330648100101462.html)：只用于动画未给出数值的外围尺度参考，第一层南端半圆城墙直径约 1 km。本轮不是证明动画与小说每个尺度一致。
5. [黑铁宫二手索引](https://swordartonline.fandom.com/wiki/Black_Iron_Palace)：将其列为广场北面的重要地标。直达 Wiki 页面受抓取限制，检索摘要可读；因此只作待校准位置。现有深色穹顶体量是占位，不声称已经还原动画外观。

官网第 11、12 话的公开剧照也进行了有界检查，但选出的六张主要为人物、室内与地下空间，不能当作完整城市外观的证据。检索中出现的托尔巴纳风车广场、Underworld 城市、游戏改编地图和同人重建均未当成起始之城测绘。

**本轮没有找到官方完整俯视地图。现有镜头足够开始搭建局部轮廓，全城街区只能作为明确标注的补全。**

## 当前如何解释这张图

| 内容 | 已确认部分 | 本轮工程选择 |
|---|---|---|
| 圆形广场 | 圆形铺地、环绕拱廊、中央塔的形体 | 地面直径 174 m、拱廊半径 96 m、出入口数与尺寸 |
| 钟塔 | 中央细长塔及台阶、钟面形象 | 塔高、各段比例与简化顶部；转移功能尚未开发 |
| 石砌街道与市场 | 动画参考图中的空间类型与立面语言 | 广场西侧的任务街地址、路宽与朝向 |
| 外围城墙 | 小说给出的半圆总体尺度 | 与广场的相对位置、具体城门、墙高及塔数 |
| 黑铁宫 | 作为城市地标，位置依据二手索引 | 当前全部几何外形、尺寸和坐标，须后续镜头校准 |
| 其余街区 | 没有逐栋证据 | 全部为灰色体量；没有绑定原作地址、居民或商店 |

蓝灰形体表示“形体有镜头依据”，**不表示每个尺寸和坐标已经官方确认**。橙色首批店面是项目位置选择，数据标记为 `project_mvp_site`；其服务类型暂未定案。深色为黑铁宫待校准体量，暖灰为后续街区补全。

## 接下来从这段轮廓开始

1. **可行走的广场与短街**：在选定引擎中导入模型，加入人物尺度、碰撞和导航，确认拱廊开口、钟塔基座绕行和市场街入口。先以地面视角核对，而不是只看俯视。
2. **一间可进入并可使用的店铺**：在市场街预留位置选择有第一层来源的服务，补齐柜台、交付点、物品位置和室内。具体商店放在此处仍标为地点补全。
3. **第一件真实事情**：沿用三人持久世界目标，运行一笔可拒绝、可交付、可付款、能实际使用结果的交易；记忆进入下次选择。街区草模不等于居民完成了建设。
4. **再连接出城路线**：只接一个有界城外场景；不是立刻实现整层战斗、所有商店或整个迷宫。
5. **逐步替换灰色体量**：根据新增动画证据或居民的真实需求迭代建筑，保留 IDs 与迁移记录。

本轮技术研究不构成引擎迁移。上一份 Godot MVP 选型仍需先完成兼容性验证；现有 UE 代码、居民、预算账本和世界存档未改动。

## 坐标与现有工程的关系

研究坐标：中央广场为 (0,0,0)，X 东、Y 北、Z 上，单位米。GLB 根节点旋转将其转成 glTF 的 Y-up。导入 UE 后应在明确的映射函数中转成厘米，不能再将根节点旋转重复应用一次。

本机现有 `HearthAincradFloorPlan.cpp` 中黑铁宫研究锚点位于广场南侧；这与本轮二手来源描述存在方向差异，已作为待查项记录，**没有直接搬动现有世界地标或更改居民位置**。待镜头方位证据充分后，再做统一迁移和冷恢复验证。

## 验证与限制

- 已检查模型生成结果、GLB 容器头与长度、节点变换、证据标签、两张输出图。
- 第一版几何预览发现地面三角形遮挡建筑，已修复投影绘制顺序；任务店面位置从普通街区生成范围排除。
- 原始生成器只检查 GLB 结构，不执行引擎验收。后续 Godot 原型已完成导入、局部碰撞、导航与玩家行走，见上方接续链接；真实 Kimi 社会验收仍未进行。
- 不是精修美术。门窗、材质、动画、正式街区密度与原作建筑细节须在地面场景阶段继续完成。
- 本轮所有自建浏览器已关闭，没有留下 UE、Blender 或后台模拟。没有付费模型请求、提交或上传。
