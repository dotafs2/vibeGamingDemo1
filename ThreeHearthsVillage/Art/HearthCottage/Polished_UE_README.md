# Polished cottage — native UE art acceptance

The polished GLB is imported as an independent combined StaticMesh under `/Game/ThreeHearths/Generated/HearthCottagePolished/HearthCottage_SharedUV_Polished`. Its original SharedUV counterpart and the main village map are retained. `Polished_UE_Import.json` contains the exact mesh path, native measurements, original asset hashes and material factors.

The new native mesh preserves all 16,788 source triangles in LOD0, one UV channel and 19 material slots. Native bounds origin and extents match source vertices after Blender `(x,y,z)` metres becomes UE `(100*x,-100*y,100*z)` centimetres. Every material instance's base colour, roughness and metallic factors match its GLB source. Four roof roughness values are 0.34, 0.38, 0.36 and 0.40, with metallic zero. The mesh now disables Nanite: runtime logging showed that Nanite had been falling back to the default material because these imported material instances had no saved Nanite usage flag, which suppressed the authored roof response. This low-poly house does not benefit from Nanite, so disabling it keeps the intended roughness/specular values and avoids recompiling the materials on every launch. The original native mesh also retains 16,788 triangles and matching dimensions; its legacy Material graph uses function constants rather than named roughness parameters, so the report distinguishes its source roughness from directly queried native values.

`/Game/ThreeHearths/Maps/L_HearthCottagePolished_Compare` is a separate copied review map with the village simulation actor removed. `Polished_UE_house_original.png` / `Polished_UE_house_polished.png` and `Polished_UE_roof_original.png` / `Polished_UE_roof_polished.png` are actual 1920 × 1080 UE screenshots. Within each pair only the house's StaticMesh changes; material overrides are cleared. Island lights and camera transforms are unchanged. House/roof views use 52/37 degree FOV respectively, with exposure bias fixed at zero for both states. No image post-processing or lighting change is used to create the difference.

The comparison visibly retains the old silhouette and hard tile ends while introducing curved, continuous ceramic reflections on the repaired roof. This is native art acceptance, not a main-map replacement, gameplay collision review or inhabitability test.

`import_polished_cottage.py` performs the import, independent native audit, isolated map creation and read-only character-reference export. `capture_polished_cottage.py capture STATE VIEW` captures one state through the dedicated local UE Python endpoint. All editor runs explicitly use the offline `Saved/ThreeHearths/import-preview/offline.json`, `-HearthNoWorldPersistence`, no PIE and no generation API calls.

Additional read-only data is saved outside the art deliverable at `Saved/ThreeHearths/ResidentKitReference/UE_ReferenceBoneTransforms.json` and `ue-material-parameters.json`. Bone transforms come directly from the mesh reference skeleton, accumulated through parents; they are not sampled animation poses. The material file records actual body slots, vector parameter names/defaults and MI parent materials. No character asset or material was changed.
