# 有机村庄运行版

2026-09-08。通过 `-HearthOrganicVillage` 启动布局 4；保留布局 2/3。

## 当前行为

- 10 名居民：9 名普通居民用 Blender 原生构件住宅，国王保留已有 keep 和税收公共工程系统。
- 三栋主样板、两档家庭扩建阶段、28 种构件。以 114 个“构件 × 材质层 × 配色”原生 StaticMesh 导入，不把整栋房屋焊死。
- 木匠、铁匠和陶工的初始房产围绕作业院落；商人使用错层商宅；其他居民根据性格使用小家或侧翼。配色随稳定居民 ID 保存，不随演员顺序变化。
- **初始房屋是明确的开局房产**，不把它们算作本轮 NPC 从零施工的成果。旧木材账以每户 6 份安家材料保持一致。初始国库 500、每人钱包 12。
- 后续扩建读取居民的安家愿望、真实交往次数、亲密关系和积蓄，并受饥饿、精力、真实库存和钱包约束。节俭、觉得够住的居民不会仅因背景文字提到“将来有家人”就扩建。较大院落需要实际交往和至少 24 币开工储备；每次采购留下至少 4 币生活费。当前决定来源是 `local_rules`；真实 Kimi 提示中也带上目前住宅及回收材料数据，但本轮未声称 Kimi 已独立选择建筑配方。
- 同一套家庭构件按 `family_starter → family_side_wing → family_cluster` 增建。保留稳定构件键，施工包含拆除、私有回收、逐件安装。每次只在完工时原子扣料扣款，公共材料每份 1 币进入国库；短缺时不扣款。
- 连续 300 米高度场使用真实碰撞网格。房屋、作坊和农地有平整基础，道路随坡度铺设；村民每一步使用实际地面三角插值高度。房屋内部与院落按不同占用格处理，不把整块地都封死。
- schema 11 保存房产、目标、原因、已安装构件、原始材料成本、回收库存和施工进度。默认新存档为 `Saved/ThreeHearths/World/organic-world.json`。
- 全村供需同时计入现有公共库存和待建构件，修复只加工木板、房梁永远不足的循环。新布局不再追加 18 个旧式空住宅地块；已保存的旧地块不会被悄悄删除。房屋只在实际装上地板后形成阻挡；开垦或树木覆盖旧站位时，可沿真实路线离开或改用附近的家门外站位。
- 114 个运行构件使用普通 StaticMesh 渲染路径，关闭自动导入的 Nanite；297 个材质槽冷读检查没有缺失。重导入脚本会保留这一设置，不改引擎或插件的共享材质。

## 在本机打开

在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\Launch_OrganicVillage.ps1
```

这份启动脚本明确关闭收费 API；正常运行保留有机村庄存档。加 `-FreshPreview` 可只看临时新场景。

源码已用 UE 5.8 Development Editor 编译。针对性验证涵盖实际清单加载、真实地形碰撞、单件施工付款、生活费保护、真实需求、旧站位恢复和状态恢复；全套 `ThreeHearths.` 原生回归 79 项通过，后续策略修正又执行了相关检查。运行检查原始证据在 `Saved/ThreeHearths/OrganicReview/`，可随代码保留的简版记录和真实游戏视口截图在 `RuntimeReview/`。

## 仍需继续的目标

- 将更多可保留旧构件的跨配方扩建规则做成完整施工链；当前不会随意把商宅整栋替换成作坊。
- 拓展职业专属空间、真正的家庭/婚姻/孩子，以及对应的居民决策。现在没有虚构配偶或子女数据。
- 更多可玩地形生态、靠地形和邻里选择的聚落生长；目前地块位置由确定性道路规划器生成，初始房产类型有职业规则。
- 建筑内行走、精细碰撞、LOD、独立涂料交易及任意材质层改装还没有完成。材质层已独立渲染，游戏内独立涂装界面尚未加入。
- 当前入口是 Unreal 项目的运行模式，未做独立发行包验收。本轮没有恢复旧的定时任务或消耗 Kimi API。
- 独立的一次性 SceneCapture 仍会把背光墙面拍暗，与正常游戏视口不同；当前交付截图使用实际游戏视口。这项截图一致性问题仍需修正。
