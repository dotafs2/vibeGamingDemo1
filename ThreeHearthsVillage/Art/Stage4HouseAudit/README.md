# 阶段 4 木结构样板房构件

本次新增两个独立木质屋面变体：`roof_slope_timber_2m` 与 `roof_ridge_timber_2m`。它们复用原陶瓦屋顶的低模轮廓、三角形、局部原点与 UV，表面改为和 VillageKit 木梁一致的栗木色，保留圆边、层叠分缝与轻微深浅变化。原陶瓦 GLB、木梁 GLB 和既有原生资产均未改动。Stage4 墙板、门洞墙、窗洞墙和山墙改用既有 timber 版本，与木结构材料链一致。主 Art/VillageKit/catalog.json 从 38 项增至 40 项，并加入 timber 屋面选项，原 38 项模块条目不变。

新增 GLB 位于 `Art/VillageKit/modules/`；源文件为本目录的 `TimberRoofVariants.blend`，其中只有两件屋顶网格。完整规格、源审计和独立字节流验证分别见 `timber-roof-specs.json`、`timber-roof-source-audit.json`、`timber-roof-validation.json`。

两件新屋顶已经通过可续传导入流程生成 UE 原生资产，`UE_Import_Report.json` 为 `passed`，源哈希与 GLB 一致。10 类选用组件和 1 个未选用单格框架原型均有有效 `.uasset`。当前组件计划器每个木屋顶构件消耗 1 木板，4 半片与 2 屋脊共 6 木板、不消耗房梁；主 catalog 两条 `resource_inputs` 已对齐，`runtime_binding` 为 `aligned_with_stage4_runtime`。完整 45 构件生命周期、库存守恒和入口寻路由 `ThreeHearths.Production.ModularCottageLifecycle` 验证。

## 原点与装配

单位为米，作者坐标 +Z 向上、-Y 为前。GLB 使用标准 +Y 向上；转回作者坐标为 `(x, -z, y)`。保留原组件局部原点，不统一重置为底面中心。

- 地基原点在顶面中心 Z=0，实体向下到 -0.24 米；楼板 Z=0…0.16，完成地面为 +0.16 米。
- 柱原点在底面中心，高 2.4 米。梁底面中心为原点，长轴 +X，实际长 1.82 米，梁底放在 Z=2.2 米。
- 墙板原点位于结构网格边界中心，填充部分 Z=0.16…2.24 米，实际宽 1.812 米，板缝作为视觉细节保留。
- 山墙原点位于 4 米端墙顶部中心。木屋顶半片原点仍在墙顶基准，屋脊沿 Y、局部约 Z=1.2 米，朝 +X 下坡；另一半绕 Z 旋转 180°。沿 Y 按 2 米拼接，组件世界 Z=2.4 米。
- 木质屋脊也使用墙顶基准，几何已在局部 Z=1.22…1.409 米；不应再次把原点移到屋脊底面。实际半片包围盒为 X=-0.043400…2.25、Y=±1、Z=-0.130000…1.284100 米。

`stage4-assembly.json` 的 `s4_cottage_4x4_timber` 沿用 `cottage_terracotta` 的结构位置，把屋顶资产 ID 显式映射到新木质件，同时将墙板和山墙映射到既有木质件。共有 45 个稳定组件实例、10 类资产，完整装配为 43,308 三角形，10 类选用源资产共 11,884 三角形。地基、楼板、柱梁的稳定 ID 保持不变；墙板、山墙与屋顶实例 ID 随对应资产 ID 明确更新。

## 碰撞与验证

碰撞数据仅是建议。地基、楼板、柱梁逐件采用简单 Box；门洞墙用左右立边和上过梁三个 Box，保持 X=±0.47、Z=0.16…2.06 米门洞清空，已用导出几何射线检查。木墙 X=0 处为原有板缝，实板检查在两侧六个板面位置取样；简单墙碰撞跨过装饰性拼缝。木屋顶沿用原底板的单个定向 Box，中心 `[1.0671, 0, 0.5584]` 米、长度 `hypot(2.18,1.2)`、宽 2、高 0.085 米，Y 轴旋转 `degrees(atan2(1.2,2.18))`；装饰木屋脊建议不阻挡。不能把开放框架或整栋房包成一个凸体。

`validate_timber_roof.py` 独立解析 GLB 字节流：检查单一单位变换节点、合法索引、非退化三角形、UV、单位法线与自包含 PBR，并与源 GLB 逐三角形比对。顶点位置、三角形朝向及 UV **完全相同**；Blender 内部法线压缩产生的最大单位向量差约为半片 0.000095、屋脊 0.000048，低于 0.00015 容差，不声称法线字节完全相同。源陶瓦和木梁哈希保持不变。

`audit_stage4_components.py` 复核 11 份独立构件及对应原生文件/导入记录、45 个稳定实例、阶段累加、无重复柱梁及门洞留空。`previews/Stage4_ComponentStages.png` 为 Blender MCP 实际 CPU 渲染的四阶段组合，`previews/TimberRoof_Components.png` 为木屋面与木梁材质对照。预览不是 UE 施工状态机截图。

MCP 创建与渲染请求在 `mcp/`；预览场景和运行日志只保留于 `Saved/ThreeHearths/Stage4TimberRoof/` 或 `Saved/ThreeHearths/Stage4HouseAudit/`。
