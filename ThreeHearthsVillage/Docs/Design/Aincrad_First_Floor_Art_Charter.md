## 实际布局

地图仍为 300×300 米：XY -8500 至 21500 厘米。主堡中心 (6500,6500)，台地高 3500 厘米；住宅、服务点、城堡实例的既有身份和 XY 保留。城堡逐构件施工，不因美术调整自动完工。

保留已入住街道，外缘道路改为经过 19 个有意安排的转折点，连接南方田野、西方林缘、东边草甸和未来扩展入口。每段细分后贴合真实地形，避开山体内侧。十个分区继续使用原来的稳定 ID，北部明确写为未探索预留；规划只是用途意向。

天然植被改为十片有边缘和疏密变化的林地，最多 200 株树、408 株下层植物，按实际地面采样摆放。使用已有两种树、两种灌木和四种草丛资产；避让房屋、现有通路、山路及施工储备地。本轮是初始自然景观调整，这些景观实例不自动增加可采资源库存。可采伐、再生和居民付费种植需要继续经过实际资源系统。

## 美术规范

目标是日式动画背景感的三维中世纪城镇：温暖灰泥、灰石、陶土和蓝灰板岩屋顶，节制的绿色，清楚的体量、柔和日光与阴影。第一版保留正常光照响应，不加全屏粗描边。

材质源文件在 `Art/AincradStyle/style.json` 和 `surface.hlsl`；`Tools/create_aincrad_style_materials.py` 在 UE 中生成 `/Game/ThreeHearths/Materials/AincradStyle/` 下的一个母材质及 11 个实例。分类包括草地、石板路、三种灰泥、石墙、陶瓦、板岩、普通/深色木材、叶色。

石墙与道路采用世界尺度的错缝纹理，灰泥采用低对比度色差。屋瓦保留构件原本的共享 UV，木材采用原 UV 的细微纹理。材质无位移，不改碰撞、模型尺寸、枢轴或现有 UV。玻璃、花朵、透明裁切植被、铁件和未识别材质保留原材质。光照、材质与摄像头应共同验证，不能用调色冒充建筑细节。

为了让逆光建筑也像动画背景一样保持色彩可读，母材质提供 `HearthAmbientFill` 环境色下限：建筑 0.14，地面/道路 0.02。它是有意选择的风格化材质效果，保留真实日光与阴影，不是新增灯具或世界中的发光能力。未来接入昼夜系统时，应一起调节这个值。日光环境采用 UE 的 `DaylightAmbientCubemap`。

新资产必须：以厘米和真实使用空间定尺寸；复用共享 UV、墙/屋顶/木构/石基材质槽；给出枢轴、碰撞、门口及占地；接入原有通用构件和验收链路。用途决定体量变化，不能只随机换颜色。棚、货院、储物间等也遵守产权、地形、通路、材料及工钱约束。

## 居民如何继续发展

1. 永久人设、自己的经历和需求保持不变；共同审美只是文化偏好，不是已建成事实。
2. 新的外观/需求版本先排入实地查看。居民沿现有导航去自己的可进入前沿，实际身体转向已知目标后，再从眼部位置、实际朝向、85° 水平 FOV 截图。保留邻人和遮挡，隐藏自己的可见身体与规划覆盖层，不把协调者鸟瞰图传给居民。已经站在入口的人只需转身，无须伪造一次远行。
3. Kimi 获得自己的身份、故事、愿望、财产和这一张图；不附加全城库存、各区位置或城堡总进度。到达自家前沿属于个人记忆，产权不需要从画面文字重新猜测。回复区分“看见 / 未知 / 打算”。看不清时选择 6 暂缓，和 0“外观满意、暂停扩建”分开。原图使用唯一编号，并嵌入居民、世界、时间、眼部位置与 FOV 元数据；需求绑定实际发送的图片。
4. 已有动作继续受原来的所有权、预算、材料、施工及通行检查约束。新物体或新规则提交给世界主持人作为待审需求，回复本身不算批准，也不直接生成免费建筑。
5. 世界主持人审核世界观一致性、是否已有通用能力、代价与受影响的人。需要新功能或模型时暂停世界，由开发者实现和验证，迁移同一存档后再继续。
6. 居民真正使用成果后再观察，形成下一次需求。看图评价不是使用成功的证明。不同 API 只升级决策层，不替换居民、世界状态或历史事实。

## 本轮验收边界

实际运行照片、原生自动化测试、同存档状态比较及真实 Kimi 费用单独写入验证记录。协调者展示镜头明确标注不是 NPC FOV。不能将未完成的城堡、规划区、天然景观实例或模型的期望视为游戏已经具有的能力。

本轮结果见 [2026-09-08 运行验收](../Validation/Aincrad_2026-09-08/README.md)，包含 UE 原图、NPC 实际 FOV、真实 API 意图与拒绝结果、费用、测试和未完成的闭环。

实地查看最多持续 300 个模拟秒，饥饿或低精力优先处理；同一外观版本不会无限重试路线或连续付费。步行中的身份和目标随世界保存；付费请求发出前消耗到达令牌，重启不能重复收费。实地查看仍看不清时回到生活，等待新事件。

仍需继续建设的闭环包括：因遮挡而选择另一个观察角度；可信亲历事件与被告知消息的记录；新能力的通用主持人验收；植物的采伐/生长/照料；功能完成后的实际使用验证。第一人称截图和美术规范是这些工作的基础，不等于整个自演化世界已经完成。
