# 中世纪社会本轮交付

这一轮增加了可分层组合的中世纪人物、马车、城门、马厩和生活物件，并把部分资源接入了真实居民行为。新增静态库是30个模块、66个网格层；人物与马的动画单独保存，没有按实例或动画重复计数。

运行项目根目录的 `Launch_MedievalSociety.ps1`，可继续查看独立的实测世界。默认关闭付费API，首次复制检查点，以后保留该世界的进度；普通村庄存档不被替换。需要本机Unreal Engine 5.8，默认路径为 `D:\UE_5.8`。
