# 有界子 agent 派工模板

模型与并发政策统一见根目录 [AGENTS.md](../../../AGENTS.md)。这是按需模板，不要求每轮启动所有角色。

```text
目标：一个具体、能展示或验收的结果。
背景：最多一小段必要世界事实；不复制完整对话。
必读：只列相关文件与函数，不让工人重读整个仓库。
可编辑：明确文件/模块；其他文件只读，有接口变更先报告。
接口：输入、输出、错误、状态所有权和兼容条件。
验收：与风险匹配的一项或少量检查；实际可见行为由根统一验收。
禁止：另起子agent、付费API、共享引擎/Blender、正式存档写入；除非明确委派这些职责。
停止：目标完成、越界依赖或同一阻断再次出现时提交短结论，不自行扩范围。
交接：修改文件、行为变化、验证证据、剩余阻断、已知用量；不确定的用量写未知。
```

默认先派一个Luna做局部工程。确有独立文件与工作时第二名可做展示接入或必要检查；共享接口先由根确认。Sol只接具体复杂问题，Astra负责最终方向和原创建模。普通读取、计数和监控用脚本。

每个阶段给一次短交接；无变化不循环消息和互审。技术检查成功后由同一世界的真实Kimi选择验收生活能力，分别标注自主、人工与回放。不凭测试数量宣称社会完成。
