# 《零时回响》矿场段共享美术与拼接规范

状态：生产基线 v1.0（2026-08-10）
适用范围：地上闸门 → 矿井电梯 → 井底实验室入口 → 实验室主体 → 防爆门 → Boss 大厅

长卷总布局见 [`docs/art-direction/continuous-master-layout.svg`](art-direction/continuous-master-layout.svg)。运行时的同源常量位于 `src/art-direction.js` 的 `ART_DIRECTION_SPEC`；数值变更必须同时更新这两处和契约测试。

## 1. 现有运行基准

- 渲染：Three.js 正交相机、高清矢量/连续色位图；禁止像素化、最近邻采样和调色板量化。
- 相机：固定世界高度 `18u`；16:9 基准视口为 `32u × 18u`，对应生产基准 `2048 × 1152px`。
- 单位：`1u = 64px`（源美术交付比例）。允许运行时线性缩放；禁止按像素网格吸附。
- 角色：站立碰撞宽 `0.76u`、高 `1.72u`，即生产图约 `49 × 110px`。
- 地面：地上 `Y=-4.55`；井底、实验室、防爆门、Boss 厅统一 `Y=-22.40`。
- 相机路径：地上横移至井口 → 以电梯轴 `X=18.25` 下移 → 井底相机中心 `Y=-18.25` → 沿实验室横移到 Boss 厅。
- 世界范围：`X=-17…116`。所有固定地标按世界坐标落位，不允许按单张图的视觉中心重新居中。

## 3. 建筑、门与平台尺寸

- 普通人员门净开口：宽 `1.2…1.6u`，高 `2.4…3.2u`。
- 实验室重门/防爆门：门叶宽 `1.55u`，门框总宽 `2.3u`，高 `6.35u`；门楣顶 `Y=labGround+7.0`。
- 电梯轿厢：宽 `3.0u`，可见高 `3.65u`；竖井内净宽至少 `3.4u`。
- 常规检修平台：厚 `0.28u`；可站立顶面必须与碰撞顶面相同。
- Boss 平台：宽 `5.4u`；相对基线顶高依次 `1.55 / 3.15 / 4.75u`，左右镜像。
- 主承重柱可见宽 `0.20…0.34u`；梁宽 `0.20…0.34u`；装饰线宽不得冒充碰撞体。
- 安全净空：角色站立通道至少 `2.1u` 高；战斗主跑道至少 `6u` 连续无硬遮挡。

## 4. 色板、材质与线条

### 共享中性色

- 深空/洞腔：`#050d11`、`#160c0d`
- 铁锈黑金属：`#18272a`、`#211315`
- 暗褐金属：`#3c211c`、`#452c23`
- 岩壁：`#10181a`、`#2a1514`
- 结构边：`#486b70`、`#9a5738`
- 时晶主光：`#56cedd`；热点仅用 `#c0ffff`

### 2047（过去/完好）

- 材质：干燥暖褐钢、完整铆钉和防锈涂层；铁锈作为局部磨损，不覆盖整体。
- 边缘：暖橙褐 `#c97743`，禁止大面积金黄或蒸汽朋克黄铜。
- 光照：左上暖白主光；青蓝时晶仅为辅光和设备状态光。
- 设备：输送带、风机、灯、实验器皿和电梯通电；活动件轮廓完整。

### 2147（现代/废弃）

- 材质：黑化钢、冷灰氧化层、缺失面板、积尘和水蚀；保持原铆钉节奏和结构尺寸。
- 边缘：冷灰蓝 `#486b70`；保留少量旧褐锈，避免全部转为纯蓝。
- 光照：左上主光仍存在但更弱；青蓝晶体、裂缝和残存应急灯成为主要辅光。
- 设备：停机、断线、破裂、局部坍塌；不得移动门洞、承重柱、主平台和世界锚点。

### 线条与细节密度

- 以 64px/u 源图计：主轮廓 `6…10px`，结构内线 `3…6px`，划痕/电缆高光 `1.5…3px`。
- 每个 32u 镜头至少包含 3 个尺度层级：大机械剪影、中型功能组件、小型铆钉/管卡；角色周围 `1.2u` 内保持低噪声。
- 任何锐利高亮不得沿整个画面形成与可走地面竞争的假平台。

## 5. 光照与色温

- 主光方向固定为左上约 `35°`；门框、柱、设备和 Boss 必须有一致的左上亮边与右下阴影。
- 青蓝辅光只从时晶、观测窗和状态灯发出；发光占画面面积不超过约 `12%`。
- 相邻区平均亮度差不超过约 `15%`；重叠带内同时出现一盏共享灯或一组共享晶体用于色温校准。
- 2047/2147 切换不得改变相机曝光或全局主光方向，只允许降低设备自发光、改变表面反射与局部光源状态。

## 6. 视差与渲染层

| 层 | 运行因子 X/Y | 内容 | 深度规则 |
|---|---:|---|---|
| L0 远景岩壁 | `0.18 / 0.35` | 大岩层、远处矿脉、洞腔 | 不含可碰撞边；最低对比 |
| L1 中景设施 | `0.52 / 0.72` | 柱列、远管道、远风机、结构窗 | 不放唯一交互提示 |
| L2 土地底板 | `1.00 / 1.00` | 洞穴、岩层、自然地面与空洞 | 禁止烘焙门、风扇、平台、管线或任何可识别模型 |
| L3 近景结构 | `0.88 / 0.94` | 地面裙边、近管线、遮缝柱 | 不得遮住角色头部和 Boss 警示 |
| L4 交互/碰撞 | `1.00 / 1.00` | 门、平台、推箱、开关、Boss | 与物理数据同坐标 |
| L5 角色/VFX/UI | `1.00 / 1.00` | 角色、武器、伤害提示 | 始终高于场景美术 |

运行实现位于 `src/art-direction.js`。背景图使用 `LinearFilter + sRGB`；禁止 `NearestFilter`。

## 7. 碰撞与交互层

- 纯背景不得注册碰撞，也不得在编辑器中标为 `pushable` 或 `static-collider`。
- 可站立平台只用单独物理数据定义；美术图中的平台边缘必须贴合物理顶面，误差不超过 `0.08u / 5px`。
- 门、轿厢、开关、历史改写物、Boss 和攻击警示都保持独立对象；不得烘焙进远景/中景。
- 所有人工设施和可识别模型，无论是否参与碰撞，都必须是透明独立组件；背景图只允许保留自然土地、岩层、洞腔和地面。
- 运动模型必须拆出真正运动的子件。例如闸门固定门框与门扇分离，门扇和物理代理共享同一个运行时驱动值。
- 交互物的默认识别轮廓比背景亮 `10…18%`，并至少有一处青蓝或暖橙状态点。
- 重叠带不放交互触发器；相邻任务可以安全裁切而不会复制逻辑。

## 8. 过去与现代的变化规则

必须保持不变：世界坐标、门洞、平台顶面、竖井轴、承重柱主节奏、相机路径、碰撞体和接缝锚点。

允许改变：表面色、锈蚀、水蚀、灰尘、破裂玻璃、缺失盖板、垂落电缆、设备开关状态、灯光强弱、局部碎石与非承重小件。

损坏原则：现代版的任何坍塌都必须能从过去版对应构件推导；禁止“为了好看”新增一堵改变通路的墙。若历史改写改变通路，变化必须由独立可交互对象实现并有明确状态逻辑。

## 9. 运行入口与验收

- 正常入口：`/`
- 内置场景编辑器：`/?editor-preview`；右上“保存并试玩”会保存资产状态并回到正常游戏。
- 低功耗预览：在任一入口追加 `&low-power`（根入口用 `/?low-power`），渲染限制为 `24fps`、`1×` 像素比；用于 Codex 侧栏试玩，降低 CPU/GPU 持续负载。
- 自动连续巡检：`/?art-tour&era=present` 或 `/?art-tour&era=past`
- 定点：`/?art-stop=gate|elevator|entrance|laboratory|blastdoor|boss&era=present|past`
- 浏览器控制台可读取 `window.__ZERO_ECHO_ART__`，其中包含规格、定点和当前相机坐标。
- 契约测试：`npm run test:art`

验收必须在过去/现代各跑一遍自动巡检；检查地面基线、角色比例、光向、色温、接缝柱、视差漂移、交互物遮挡和 Boss 攻击警示。只看长卷母图不算完成。
