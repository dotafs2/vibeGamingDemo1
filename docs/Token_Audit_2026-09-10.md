判断：旧 10M–40M 全量 MVP 预算未用本项目实际运行方式校准，应撤回。输入上下文反复处理占主导，值得优先缩短任务上下文、减少重复协调和无变化轮询。不能将缓存 token 当成免费，也不能将原始 token 总数直接换算订阅额度或金额。产品层面应先锁定招募演示的可见成果，避免继续扩大到完整社会和双引擎维护。


合计：输入94,205,564；其中缓存91,999,616；未缓存输入2,205,948；输出357,555；总计94,563,119。缓存占输入约97.66%，不代表免费或订阅额度比例。
