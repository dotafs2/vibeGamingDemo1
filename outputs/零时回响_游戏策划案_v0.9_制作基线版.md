# 《零时回响》游戏策划案 v0.9（制作基线版）

> 本版本用于制作两小时垂直切片。它封闭已知的主线因果、唯一物品、终局锁点和沙盒软锁规则，但不以文字预先宣称手感已经优秀；挖掘、近战、时代切换和Boss质量仍以第6.12节的原型验收为准。

> 暂定名；类型为 Steam 平台 2D 横版沙盒动作冒险。  
> 本版本用于锁定核心体验、时间规则、主线结构、双人团队制作范围与首个可玩原型，不代表最终数值表。  
> 排期假设：两名成员均为全职，GPT用于辅助代码、测试、工具和内容草稿；如为业余开发，所有周期需要重新估算。

## 已确认方向

| 项目 | 当前决定 |
|---|---|
| 平台 | Steam / PC，键鼠优先，同时预留手柄操作 |
| 模式 | 纯单人；1.0不做在线／本地合作、PvP、专用服务器或公开匹配 |
| 视角与操作 | 2D横版，挖掘、建造、平台跳跃、鼠标瞄准与快捷栏操作接近《泰拉瑞亚》 |
| 一周目长度 | 1.0新玩家约25—35小时；熟练玩家约18—25小时；全收集约45—55小时 |
| 世界 | 随机生成；过去、现代、未来共享同一个基础世界种子与地形骨架 |
| 角色 | 外观、名字与装备路线均可自定义；主角不使用大量固定内心独白 |
| 战斗 | 无固定职业；近战流派最多，远程分枪械与弓箭，召唤物全部现代化、机械化 |
| 装备 | 探索掉落、怪物掉落、Boss核心与制作系统共同组成 |
| 死亡 | 普通死亡掉落一定比例的随身金钱，不掉装备；剧情秒杀不掉钱、不计入死亡 |
| 主线时间结构 | 现代开局；三次主要过去远征；两次主要未来远征；Boss共四次直接遭遇 |
| 通关后 | 保留自由穿越、Boss残响挑战，并允许调整已解锁的世界风貌 |
| 引擎与语言 | Godot 4.7.1稳定版.NET；生产代码统一使用C# |
| 首发系统 | Windows x64；Steam Deck/Proton先测试后再标注支持，不在未验证前宣传 |
| 商业模式 | 一次性买断；1.0不做内购、通行证、实时生成AI内容和Steam创意工坊 |

删除联机后，省下的工期只用于稳定挖掘战斗手感、三时代存档和历史结算，不增加Boss、生态区、装备或历史节点上限。每个世界拥有一份独立角色进度；外观预设、键位、成就和全局图鉴可跨世界共用，装备、背包、货币、任务与世界历史不能跨世界携带。

v0.1中18个完整Boss、百余战斗配置和七个基础生态区对双人团队过大。v0.9将1.0生产基线收口为六个基础生态区、10套完整Boss配置、48套常规敌人／变体／精英配置、最多6个历史节点和120—140件功能装备。以上是硬上限，不是必须填满的清单；目标是保留“类似《泰拉瑞亚》的成长与沙盒循环”，不复制其多年更新后的内容总量。

# 第一部分：核心体验与设计支柱

## 1.1 一句话概念

玩家在同一个随机世界的过去、现代与未来之间探索、挖掘、建造和战斗，通过改变过去重塑现代，并在已经毁灭的未来击败试图冻结时间的赫洛恩。

## 1.2 玩家幻想

玩家不是观看一段时间穿越故事，而是亲手完成以下体验：

- 在现代发现一片废墟。
- 回到过去，看见它曾经繁荣的样子。
- 通过探索和战斗改变这里的历史。
- 回到现代，亲眼看见城镇、NPC、生态和资源发生变化。
- 进入未来，观察自己的历史行动最终产生了什么结果。
- 建造能够跨时代保存和投影的基地。
- 用过去与现代获得的装备，对抗来自未来的敌人。

## 1.3 四项设计支柱

### 支柱一：同一地点，三个时代

三个时代不能是三张彼此无关的换皮地图。山脉、洞穴、矿脉和大型地标必须能够相互辨认；时代差异通过建筑、生态、通路、敌人和历史状态表现。

### 支柱二：变化首先由玩家看见

改变历史后，优先使用地形、灯光、音乐、NPC生活、敌人种类和商店变化表现结果。说明文字只负责补充，不能代替玩家亲自观察。

### 支柱三：沙盒自由高于剧情催促

主线没有现实时间倒计时。每次主线推进后都留出明确的自由探索阶段，让玩家挖矿、建造、刷装备、挑战可选Boss和研究时间残响。

### 支柱四：困难来自规则，而不是作弊

正常Boss不读取玩家按键，不无条件躲避，不在失败前锁血。前两次赫洛恩遭遇属于明确标识的剧情事件；第三与第四次战斗遵守完整、可学习、可重复的战斗规则。

## 1.4 核心循环

探索生态区  
→ 获得材料、NPC、装备与历史线索  
→ 制作工具并解锁移动能力  
→ 击败区域Boss或时间装置守卫  
→ 开启新的时代坐标  
→ 改变历史节点并离开时代  
→ 结算现代与未来变化  
→ 返回旧区域寻找新道路与新资源  
→ 建造、强化并进入下一阶段

每个主线Boss至少必须带来一项实质变化：

- 新的移动能力。
- 新的挖掘等级。
- 新的时代旅行能力。
- 一个区域的历史改写。
- 一个新的制作体系。
- 一条通往未来或过去的道路。

不能只掉落数值更高的武器。

## 1.5 基础操作

- 左键：主攻击、挖掘、放置。
- 右键：武器副动作、格挡、瞄准或装置交互。
- 快捷栏：武器、工具、药剂与建造物快速切换。
- 智能光标：辅助挖掘、铺墙、搭平台和连续放置。
- 移动能力逐级解锁：冲刺、钩爪、二段跳、滑翔、墙面抓附、短距离相位移动。
- 所有按键允许重新绑定；手柄使用径向建造菜单与目标辅助。

手柄首轮规则：

- 右摇杆控制自由准星，进入建造模式后自动吸附到8格范围内的方格；十字键微调单格位置。
- 肩键切换快捷栏，长按时间键打开三方向纪元选择；选择界面暂停世界，确认后进入可被敌人打断的穿越引导。
- 瞄准辅助只在视线可达、约20度锥形范围内轻微吸附敌人，不跨墙锁定，也不替玩家自动选择Boss弱点。
- 背包提供“附近配方”“最近拾取”“收藏装备”和一键整理，但不自动把快捷栏武器存入箱子。
- 垂直切片必须分别用纯键鼠和纯手柄完整通关，不能把手柄支持推迟到内容Beta再补。

## 1.6 体验边界

本作不以大量固定对白、复杂善恶数值或数十条互斥结局为核心。世界变化主要由玩家完成了哪些实际行动决定，而不是由一组选项框决定。

## 1.7 相近作品与差异位置

以下作品是设计参照，不等于直接竞品：

| 作品 | 相似部分 | 本作必须做出的区别 |
|---|---|---|
| 《Chrono Trigger》 | 多时代旅行、改变过去影响后世 | 本作是可挖掘建造的随机世界，变化必须作用于长期存档与玩家基地 |
| 《Day of the Tentacle》 | 三个时代的人物协作和因果谜题 | 本作以动作、Boss、装备和沙盒探索承载因果，而非纯点击谜题 |
| 《The Legend of Zelda: Oracle of Ages》 | 过去与现在相互影响、同地点变化 | 本作拥有三个时代、随机地图、持久历史改写和建筑保存 |
| 《The Messenger》 | 2D同一地点跨时代变化 | 本作不能只换美术和路线，需要持久历史改写与NPC人生变化 |
| 《Timespinner》 | 2D时间旅行、过去与未来探索 | 本作不是手工线性类银河战士恶魔城，而是分块沙盒世界 |
| 《Cris Tales》 | 同时观察过去、现在、未来以及选择结果 | 本作把因果变化落到地形、资源、城镇和建造，不以回合制叙事为核心 |
| 《Titanfall 2》“Effect and Cause”关卡 | 同坐标即时切换时代解决战斗与路线 | 本作把这种切换扩展为数十小时持续存档，而不是单个关卡机关 |
| 《Terraria》《Starbound》 | 2D挖掘、制作、建造、装备和合作 | 这两类作品没有本作的固定锚点、时代结算和历史改写主循环 |

这些作品已经使用过“穿越、改写历史、同地点不同年代”等单项创意。因此，本作不能把“有三个时代”当作独特卖点。

真正的差异化组合是：

1. 同一个随机种子生成可辨认的三时代世界。
2. 玩家改变过去后，现代城镇、NPC人生、资源和未来废墟永久改变。
3. 玩家长期建筑和容器在历史结算中仍然安全。
4. 玩家可以反复在被自己改变过的世界中生活、建造和挑战Boss。

如果最终只实现“过去地图、现代地图、未来地图各通关一次”，本作会迅速退化为常见的时间旅行题材游戏。

## 1.8 防俗套叙事原则

- 不使用“未来人拿出预言，宣布主角天生是救世主”。主角只是出现在赫洛恩的死亡信号中，是Boss先把普通人推入闭环。
- 不让岚隐藏一个“其实他才是最终反派”的廉价反转。冲突来自他对旧未来的依恋和身体相位不稳，而不是突然背叛。
- 不让赫洛恩只因为怕死而毁灭世界。他同时承受被改写历史的多重记忆，并由此形成“只有唯一、静止的历史才真实”的极端信念。
- 不把三座装置写成颜色不同的三把钥匙。每座装置必须是一个生态区的真实基础设施，有居民、生产用途、独立探索机制和对应时代后果。
- 不用未来尸体、墓碑和记录羞辱玩家“当年什么都没做”。主角通过亲眼观察和主动完成任务形成动机。
- 不连续使用长过场解释时间规则。每条规则先通过一次可以操作的事件展示，再由简短对白命名。
- 不在开场告诉玩家Boss必败。固定点真相放在第一次未来远征后逐渐揭示。

# 第二部分：时间穿越规则

## 2.1 三个时代

| 时代 | 时间位置 | 赫洛恩状态 | 世界状态 |
|---|---:|---|---|
| 过去 | 现代前60年 | 约30岁，时晶研究员 | 原始生态更完整，时间设施仍是早期原型 |
| 现代 | 第0年 | 约90岁，集团首脑 | 工业扩张，部分矿区废弃，未来信号刚刚抵达 |
| 未来 | 现代后40年 | 约130岁，与零时引擎融合 | 叠时灾变发生约17年，三个时代开始错误重叠 |

总跨度100年。赫洛恩依靠时晶维持身体连续性，因此能跨越整个时间段。过去被救的8岁孩子在现代约68岁，可以合理地对主角产生似曾相识的感觉。

## 2.2 固定锚点与可变历史

本作不采用“所有事情从一开始就已经注定”的严格闭环，而采用“少数固定锚点闭环＋大部分历史可变”。

时间系统只有两种数据层：

- **可变历史层**：城镇、生态、道路、NPC人生和未来社会，随历史节点结算而重写。
- **时锚记录层**：在历史结算前已经由时间机器正式注册并分配`causal_anchor_id`的旅行者、信号、剧情唯一物品和事件快照。普通目击、截图、NPC记忆和玩家看见过的城镇不构成锚定。

固定锚点只在零时引擎仍然运作时强制维持。最终战先产生死亡信号，再摧毁零时引擎；此后旧闭环不再要求新未来重复生成另一个赫洛恩，但死亡信号仍有来源——来源就是已经完成并被封存的起源残响。起源残响是只读的战斗与剧情快照，不是第四个可持续模拟的时代。

时锚注册遵守以下硬规则：

1. 一个`causal_anchor_id`只允许对应一个活体身份、一个剧情唯一物品或一份事件记录，不能同时生成两个实体。
2. 活体必须亲自穿过完成校验的时间机器才能注册；普通NPC被主角看见不会自动获得时锚。
3. 信号必须在发送完成时写入记录层；未完成的传输会随原历史一起消失。
4. 原时间线被替换后，事件记录转为只读残响，只能回放，不能再次向主世界发信号、结算历史或产出唯一物品。
5. 活体旅行者继续存在，但占用唯一身份槽。新历史会形成不同的家庭关系与出生结果，不再诞生完全相同的第二个个体；游戏不表现“婴儿被抹除”。
6. 零时引擎毁灭后不能新增`causal_anchor_id`，已经完成的记录只保留来源证明，不再拥有强迫未来重复的力量。

`causal_anchor_id`与普通物品的`item_instance_id`必须分开：

- `item_instance_id`由世界存档生成，所有可拾取、制作、掉落和放置的物品都拥有，用于容器事务和防复制；零时引擎毁灭后仍可正常创建。
- `causal_anchor_id`只授予活体时间旅行者、死亡信号、剧情唯一核心和事件快照，用于证明跨历史结算的身份与来源。
- 玩家时间机器负责把已有实体运输到另一个时代；零时引擎负责强制固定因果。终局摧毁后，玩家仍能携带新制作物品穿越，但不能登记新的固定历史事件或重开已经封存的因果节点。

固定锚点：

1. 未来NPC岚一定会离开毁灭后的未来，并抵达现代。
2. 未来赫洛恩在最终败亡时，零时核心的自动死亡协议一定会向现代的自己发送警告。
3. 现代赫洛恩一定会因为警告而开始追查主角。
4. 过去的赫洛恩一定会活到现代，因此无法被主角永久杀死。
5. 主角一定会抵达零时引擎核心。
6. 零时赫洛恩的跨时代连续存在一定会被主角终结。

固定点不是“宇宙偏爱某个人”，而是一个事件的产物已经出现在自身原因之前。例如现代已经收到未来赫洛恩的死亡信号，那么零时引擎被摧毁前，历史既要产生这段信号，也要保留促使主角进入闭环的因果链。引擎毁灭后的最终结算则把已经发生的因果链封存为起源残响，让新的未来可以脱离闭环继续发展。时晶研究、集团扩张和零时引擎原型在警告抵达前已经存在；警告只让赫洛恩锁定主角、加速计划并制造追杀，不是技术、野心或灾难的凭空起源。

死亡警告不是赫洛恩败亡时临时作出的理性选择。现代赫洛恩在零时核心中预装了不可由未来人格单方面取消的自动协议：核心检测到连续体崩溃时，会把最后一段感知、致死对象轮廓和时间坐标压缩发送。赫洛恩知道该协议把主角推入闭环，却仍不敢在更早阶段拆除，因为协议也是其现代肉体受未来核心回滚保护、跨时代意识保持同一身份的因果凭证。保留协议会带来注定的对手，拆除协议则会立即失去他最重视的连续存在。

可变内容：

- NPC是否获救以及之后拥有怎样的人生。
- 村镇是废墟、勉强存续还是繁荣。
- 森林、矿区、沙漠与雪原的生态状态。
- 现代商店、交通路线、制作台和支线任务。
- 未来幸存者数量和重建程度。
- 可选Boss、敌人和资源是否出现在主世界。
- 最终世界风貌以及部分角色结局。

固定锚点只保证“某件事最终会发生”，不保证它以原来的方式发生。这个规则称为“因果补偿”：

- 摧毁时髓采集井后，赫洛恩仍会活到现代和未来，但不得不用机械器官与不稳定时晶替代完美续命，因此失去无限重构能力。
- 摧毁先见观测阵不会阻止最终死亡信号，因为那段信号由零时核心的败亡能量发送；它只会让赫洛恩失去长期、精确预测玩家行为的能力。
- 摧毁恒日熔炉不会让最终战从历史中消失。赫洛恩会在未来建造两个效率较低的应急稳定器，所以第二次未来远征仍然成立；玩家必须在正式决战前关闭它们。

因果补偿不是无限制的剧情修补。零时引擎只有三层“应急锚储备”，分别对应三座过去装置；玩家每摧毁一座装置，就迫使赫洛恩消耗一层储备并使用策划案预先列出的低效替代方案。替代方案只能调用当时已经存在的设施，不能复活NPC、重建被毁装置、创造新能力或撤销生态与城镇变化。堡垒外观、赫洛恩动作和核心界面会依次出现三道裂痕，让玩家看见补偿资源正在耗尽。第三层用尽后不再允许新增因果补偿。

### 闭环如何真正结束

1. 最终赫洛恩败亡，零时核心触发自动死亡协议，释放能量并把警告发回现代。
2. 主角在信号发送完成后摧毁零时引擎，固定锚点失去继续强制历史重复的能源。
3. 引擎坍塌前，岚启动已经登记的返航锚，把主角与岚送回现代中央时间机器；活体不会留在即将被替换的旧未来中。
4. 系统进行最后一次历史结算：旧灾变未来被封存为起源残响，新未来从现代继续生长。
5. 现代赫洛恩失去未来意识回流、三个装置带来的能力以及集团对时间技术的垄断，被已经铺垫的时序审判机构隔离监管。
6. 新未来坐标稳定后重新开放；玩家与岚第一次主动进入新未来观看重建结果。新未来不再生成第二个零时赫洛恩，重打最终Boss只能进入只读残响。

因此，“Boss必须被主角击败”是旧闭环成立的条件；“击败后引擎被摧毁”则是闭环不必无限重演的出口。

## 2.3 记忆规则

- 主角、岚和赫洛恩拥有时锚，可以保留历史改写前后的记忆。
- 普通NPC只记得最新历史，并认为自己一直生活在这段历史中。
- 受到时间污染的少数NPC会出现梦境、熟悉感或记忆碎片，但不能完整记住旧世界。
- 不使用“未来记录责怪主角当年什么都没做”的桥段。主角的行动动力来自亲眼看见灾难和主动改变现实，而不是被剧情羞辱。

## 2.4 历史结算时机

### 各时代的时间流逝

- **剧情日期**决定第0日、第21日和第63日三个远征窗口，只在完成历史节点并离开时代时推进；它不等于玩家看到的昼夜循环。
- **本地模拟时钟**驱动昼夜、天气、作物与NPC日程。一个昼夜是可重复的玩法循环，不表示剧情日历真的过去一天，因此玩家长期建造不会越过下一个主线窗口。
- 过去、现代和未来分别拥有本地模拟时钟；玩家不在某时代时，该时代的敌人、物理和NPC移动暂停。
- 重返一个时代时，作物、商店和公共工程只按“离开后累计的有效游玩时间”结算，最多补算一个生产周期；连续跨时代往返不能反复刷新商店或瞬间催熟作物。
- 同一商店的补货冷却和同一作物的生长进度保存在世界级ID中，不因切换时代、保存读取或进入残响而重置。
- 三次过去远征属于同一年内三个不重叠的剧情窗口，不制造三条过去分支。
- 主线推进只由历史节点结算触发。自由挖矿、造房和离线不会让城镇被毁，也不会使任务因“来晚了”永久失败。
- 地图界面始终显示当前时代的本地时钟；跨时代切换不会把所有时代强制成相同昼夜。

这条规则保证沙盒玩家可以安心建设，也避免后台同时模拟三个完整世界。

### 为什么不会遇见另一个自己

- 时间机器不能把同一名时锚个体送入其已经占据的时间区间，界面将这种限制显示为“自我重叠封锁”。
- 每次过去远征结束后，下一次只能抵达前一次离开之后的历史窗口；已经发生的救援、建筑和装置破坏作为前置状态保留。
- 玩家可以回访已完成窗口的后继时刻，但不能回到任务开始前重新选择或复制首通奖励。
- Boss与关键剧情的原始时刻只通过时间残响重放；残响不改变主世界，也不生成第二个玩家实体。

这样三次远征仍属于同一条过去历史，同时不会出现玩家与自己的副本相遇、反复阻止自己完成任务的问题。

玩家在过去活动时，现代和未来不会实时重生成。

历史只在以下节点统一结算：

- 使用时间机器离开当前时代。
- 激活大型时代出口。
- 完成主线装置的破坏并确认返回。

结算过程：

1. 保存当前时代与玩家建筑。
2. 记录已经完成的历史节点。
3. 生成现代与未来的区域覆盖层。
4. 检查玩家建筑、箱子和NPC位置冲突。
5. 创建一次自动回滚备份。
6. 播放简短穿越效果。
7. 让玩家通过实际探索发现变化。

系统不在玩家放置一个方块后立即刷新另外两个时代。

### 方块级改动与历史级改动

这是沙盒玩法必须明确的边界。

玩家在过去进行的普通挖掘、搭桥、基地建设和敌人击杀，默认只保存在过去层，不逐格传播到现代和未来。世界给出的解释是：

- 时间旅行者直接携带和改变的物质受到时锚包裹，属于“时外痕迹”。
- 普通隧道在六十年中可能坍塌、填埋或被重新开发，不能简单把过去每个空格复制到现代。
- 普通敌人不代表历史中的唯一个体，击杀不会导致未来整个物种消失。

只有满足以下条件的“稳定因果”会向后传播：

- 完成正式历史节点。
- 改变关键NPC或组织的长期行动。
- 摧毁三座时间装置。
- 激活一个经过系统验证的因果工程。

1.0不支持把任意玩家建筑自动老化并传播六十年，这对双人团队的生成、碰撞和美术成本过高。后期只在少量预设“因果工地”中提供桥梁、升降机、避难所等公共工程；玩家选择方案、材料和部分外观，现代加载对应的预制后继状态。私人基地跨时代出现继续使用时锚投影，不属于历史传播。

界面必须在玩家施工时区分：

- 蓝色时锚标记：只属于当前时代。
- 金色因果标记：结算后会改变后世。
- 紫色投影标记：只是跨时代基地投影，不产生第二份材料。

不能让玩家依靠猜测判断一次大型建设是否会影响现代。

### 跨时代物品与资源防复制

- 玩家背包中的每件物品拥有唯一`item_instance_id`并受旅行机器的运输封装保护，可以跨时代携带，但同一ID不能同时存在于两个容器或地面实体中。
- 玩家可以在过去使用未来装备战斗或建造私人基地，但普通NPC不会接受超时代物品作为任务答案。只有正式“因果工地”界面会消耗允许影响历史的材料。
- 木材、石料和时代专属普通矿物在各时代独立生成，允许作为沙盒资源重复采集。
- 用于终局装备、永久升级和高价值交易的“因果矿脉”在三个时代共享一个枯竭ID。玩家在任一时代采尽后，其他时代同坐标只留下低价值残矿；地图以金色裂纹提前标识这种矿脉。
- 主线Boss核心在每个世界只发放一次。残响重战只掉落常规材料、外观和记录奖励，不重复发放进度核心。
- 投影建筑与共享箱仍只引用同一实体和容器ID，拆除投影不会返还材料。
- 所有主线钥匙、坐标、装置权限和Boss核心在取得时立即写入世界进度账本；背包图标只是访问凭证。凭证被投入岩浆、留在休眠时代、存进普通箱子或因旧版本迁移丢失时，时间机器只能恢复同一`item_instance_id`的凭证，不能重复发奖。
- 普通超时代物品带有不可融入公共历史的蓝色运输封装；NPC拒绝将其作为历史任务材料不是无解释的游戏限制。只有因果工地会解除封装、核验来源并永久消耗材料，界面必须提前显示这一结果。

这允许玩家享受三个时代的资源差异，同时阻止在同一坐标反复切换复制终局矿物、Boss核心和箱内物品。

## 2.5 穿越能力的成长

### 初期：中央时间机器

第一次穿越必须回到现代出生点附近的时间机器。时核是永久升级，不把每次旅行变成重复刷燃料。

中央时间机器、公共时锚门和剧情必经落点拥有一个不可被岩浆、线路或玩家方块永久封死的安全核心。玩家仍可在外圈建设；若目标落点周围30格内没有合法位置，系统把玩家送到同区域的人工验证备用平台，并在地图标明原因。每次设置出生点、时代切换和历史结算后都重新验证落点；绝不通过删除玩家建筑制造安全位置。

### 第一次过去远征后：时锚门与双时代薄弱点

玩家可以在已激活的大型时锚门之间往返。每个主要生态区至少有一个可修复的时锚门。

部分预设“时间薄弱点”允许玩家在同一坐标切换过去与现代，用于探索谜题、捷径和隐藏资源。该能力在游戏前期出现，避免时间穿越长期停留在章节选择层面。

### 第一次未来远征后：三时代薄弱点

已经激活的薄弱点增加未来层。玩家开始用三个时代的地形差异解决路线问题，但仍不能在任意位置切换。

### 第二次过去远征后：便携相位针

玩家在非战斗安全区持续引导数秒，可以：

- 返回最近的已激活时锚。
- 在过去与现代之间进行同坐标安全切换。

受到攻击会中断，不允许用来无成本逃离Boss。未来层仍主要通过薄弱点和时锚门进入。

### 第三次过去远征后：完整相位罗盘

探索期间可以在同一坐标附近切换过去、现代和未来。系统会搜索安全落点，不能把玩家传进实体方块、岩浆或封闭Boss房。切换有短暂引导和冷却，但不消耗普通矿物。

主线地牢、Boss房和未解锁生态区带有“因果封锁边界”。相位罗盘不能越过这些边界寻找落点，避免玩家从另一个时代直接传入锁门背后。边界必须在地图和相位罗盘上可见，不能用无提示传送失败阻止玩家。

### 通关后：纪元漫游模式

除Boss、入侵和特殊剧情区域外，玩家可以自由切换时代，并使用纪元编织台调整区域风貌。

纪元漫游模式不能回到历史节点完成前撤销救援或复领首通奖励。节点重演、旧Boss与灾变未来均通过只读残响进入；主世界只保留已经结算的新历史。“漫游”表示自由访问已经稳定的时代，不表示可以无限改写主线历史。

最终结算后，三个主线过去窗口转为“闭合历史”：玩家可以在其后继时刻继续挖掘、建造、采集和完成尚未结束的普通支线，但不能返回赫洛恩仍在现场的原始事件时刻，也不能新增会重写现代的第七个历史节点。纪元编织台调整的是已解锁自然风貌，不重新开启因果链。

三次过去远征和两次未来远征是主线的大章节数量，不是限制玩家只能穿越五次。坐标解锁后可以反复返回探索。

### 最终因果封存与未完成节点

进入零时引擎核心前，终局门显示一次不可误触的“因果封存确认”，列出六个历史节点的完成状态和将保留的区域结果：

- 三个主线节点必定已经完成，不允许出现缺少核心削弱的非法终局状态。
- 未完成的可选节点不会阻止通关，也不降低主线结局评级；界面明确提示其地区将按当前状态进入新未来。
- 确认后仍可取消并返回世界。只有击败最终Boss、死亡协议完成发送且玩家主动摧毁零时引擎后，节点才永久封存。
- 通关后可在只读残响中补战斗、图鉴、记录和常规装备，但不能把残响结果合并回主世界，也不能补领历史改变专属的城镇风貌。
- 系统保留一份终局确认前检查点供崩溃恢复，不把它作为可与通关世界互相合并物品的平行存档。

## 2.6 普通死亡与剧情秒杀

普通死亡：

- 掉落50%的随身金钱，银行和保险箱内金钱不掉。
- 不掉武器、装备和材料。
- 回到最近出生点或时锚；Boss房没有玩家后按各Boss规则重置，不保留已造成伤害。

前两次赫洛恩剧情秒杀：

- 进入遭遇区前自动保存角色、弹药、药剂和金钱快照。
- 玩家进入缓冲区后封门；遭遇开始前完成一次原子快照，异常退出时按进入前状态恢复。
- 屏幕显示“时间封锁：物品状态冻结”。
- 玩家不能打开背包或更换装备，但当前快捷栏武器仍可使用。
- 弹药和消耗品在回溯后恢复到进入前状态。
- 秒杀后不掉钱、不计入死亡统计、不损坏连胜或硬核挑战记录。
- 第一次遭遇不显示正常Boss血条；第二次明确显示“扫描／生存目标”，不伪装成可正常击杀的Boss。
- 账号已经完整体验过对应遭遇后，新角色与新世界可以选择“快速回溯”直接进入结果。

锁定物品栏必须有明确视觉、音效和文字反馈，不能让玩家以为游戏发生故障。

## 2.7 过去的赫洛恩为何不能被杀死

过去赫洛恩的存活是固定锚点。如果他在过去死亡，未来Boss不会发送警告，主角也不会得到回到过去的原因，形成无来源矛盾。

游戏表现：

- 玩家可以摧毁赫洛恩的研究设施、机械代理和实验体。
- 一次剧情中，实验室爆炸本应杀死赫洛恩，但局部时间倒退数秒，将他的死亡撤销。
- 赫洛恩仍会受伤、失去资源并改变计划，但不能在过去永久死亡。
- 后续不再给过去赫洛恩设置虚假血条；玩家对抗的是他的装置和守卫。
- 每个装置被毁后，过去赫洛恩都会在区域重新开放前撤离；自由探索和通关后回访发生在他的离开之后，主世界不会保留一个可以反复攻击的年轻赫洛恩NPC。
- 想重看爆炸、追逐或过去赫洛恩本人，只能进入不结算历史的只读残响。零时引擎毁灭意味着旧固定点不再强迫未来重演，不意味着玩家可以重新打开已经闭合的故事日期杀死他。

“时间修正”只保护策划案列出的固定锚点，不能用于随意挽救其他角色或解释剧情漏洞。

## 2.8 单人时间与世界存档规则

- 同一时刻只模拟玩家当前所在时代；另外两个时代保存逻辑状态并休眠，不在后台推进敌人与物理。
- 首次结算历史节点时显示变更摘要和明确确认；普通重复穿越直接执行，不设置投票或倒计时。
- 长按时间键打开纪元选择时暂停世界；确认后开始可被敌人打断的穿越引导，Boss封锁区内不可使用。
- 系统菜单始终暂停。背包和地图是否自动暂停由玩家设置，默认关闭；开启后同样会冻结Boss、投射物和计时器，不制造单方面优势。
- 自动存档采用五份轮换备份；历史结算、Boss首杀、进入新未来前额外建立检查点。
- Steam Cloud发现本地与云端冲突时保留两份并让玩家选择，不按时间戳静默覆盖。

### 角色与世界存档归属

- 外观预设、键位、成就、辅助功能设置和全局图鉴属于玩家账号。
- 装备、背包、货币、任务、角色数值与历史节点属于具体世界。
- 创建新世界时可以复用外观预设，但必须从初始装备开始；1.0不允许把终局装备或Boss核心带入其他世界。
- 每个世界只绑定一份进行中角色状态。允许复制整份世界作为备份或挑战档，但不能只复制角色库存。
- 这一规则牺牲跨世界携带装备的自由，换取稳定的成长曲线、历史因果和更少的复制漏洞。

# 第三部分：世界、地图和时代变化

## 3.1 随机世界生成原则

世界生成分为四步：

1. 用世界种子生成基础高度、山脉、洞穴、主矿脉和生态区边界。
2. 在固定“地标插槽”中放入矿镇、观测站、能源炉、地下遗迹等大型结构。
3. 根据同一基础骨架生成过去、现代和未来的时代覆盖层。
4. 根据历史节点状态加载城镇、污染、道路、敌人和资源变化。

随机化只改变局部路径、洞室、资源密度和地标细节，不随机打乱主线宏观拓扑：

`出生丘陵／废矿` → `雾孢湿林与集团观测站` → `第一次未来远征` → `冻钟雪原与天穹群岛` → `赤砂盆地与熔核深层` → `未来零时裂境`

- 废矿与时间机器始终位于出生点同侧的首个安全生态区。
- 湿林、雪原和赤砂可以分布在出生点不同方向，但主线解锁顺序由工具与地标门控制；生成器不能让一个未解锁生态区成为抵达当前目标的唯一通路。
- 赤砂与熔核共享至少两个连接点，一个依赖主线工具，一个是熟练玩家捷径。
- 天穹群岛必须在获得滑翔后可达，不能随机生成在基础钩爪就能绕过封锁的位置。
- 每个主线地标拥有两个人工验证的备用插槽；五次局部重投仍失败时使用后备模板，不发布不可通关种子。
- 主线地牢外壳、装置支撑和关键背景墙使用在地图与镐头提示中可识别的“时序强化等级”。未达到阶段镐力或剧情权限时不能破坏；解锁后恢复正常沙盒破坏。禁止用无提示的隐形不可破坏墙堵路。
- 关键机关至少保留一个不可被挖掘绕过的结构完整性区域；策划主动支持的熟练玩家捷径会用裂纹、旧通风道或高镐力材料标记，并纳入种子测试，其他绕过视为生成错误。

三个时代必须满足：

- 大型山脉轮廓一致。
- 主洞穴与主矿脉大致对应。
- 同一地标的横向坐标基本一致。
- 入口可以因坍塌或建设产生偏移，但不应让玩家完全无法识别。
- 每个生态区保留一个跨时代不变的视觉地标，例如巨树、断峰、钟塔基础或巨大化石。

不能分别随机生成三张互不相关的地图。

## 3.2 基础生态区

正式版目标为六个基础生态区，加一个未来终局区域。林海与盐沼合并为同一套湿润生态资产，减少双人团队需要制作的地表、敌人和音乐数量。

| 生态区 | 过去 | 现代 | 未来 | 核心玩法 |
|---|---|---|---|---|
| 绿脊丘陵与时晶矿区 | 繁荣矿镇、完整铁路、早期实验室 | 废弃矿区或改写后的工匠镇 | 玻璃化矿坑、重复坍塌的隧道 | 新手挖掘、第一时核、历史变化教学 |
| 雾孢湿林 | 巨型原始森林、湖群与药用孢群 | 盐沼、伐木设施、沉船和污染隔离区 | 生物机械孢海与被淹城市上层 | 毒素、攀爬、水下探索、生命类装备 |
| 赤砂盆地 | 地下日照遗迹、早期能源实验 | 铁路城与采能塔 | 熔融玻璃风暴、断裂列车 | 高温、高速载具、枪械材料 |
| 冻钟雪原 | 山顶观测院、自然冰穴 | 气象站与封锁区 | 时间被冻结的暴风雪 | 滑行、抗寒、预测装置 |
| 熔核深层 | 原始岩浆与古代矿脉 | 地热工厂、深层钻井 | 零时引擎输能管网 | 高级矿物、重型近战、恒能装置 |
| 天穹群岛 | 天然浮岛与迁徙生物 | 通信站、飞艇航道 | 破碎未来堡垒与重力异常 | 滑翔、空战、召唤无人机 |
| 零时裂境 | 不存在 | 不存在 | 三个时代叠加形成的终局区域 | 第二次未来远征、第三与第四次赫洛恩遭遇 |

六个生态区不是十八张独立地图，而是六套地形骨架加时代覆盖层。

## 3.3 三次过去远征

### 过去远征一：时髓采集井

地点：绿脊矿镇地下。  
作用：赫洛恩最早用于维持身体连续性的装置。  
守卫Boss：时髓巨虫。  
破坏结果：未来赫洛恩失去无限重构身体的能力；现代废矿根据玩家救援程度变成避难站、存续矿镇或工匠城镇。

### 过去远征二：先见观测阵

地点：冻钟雪原与天穹群岛交界的观测院。  
作用：计算对手可能采取的动作，并把结果送往未来。  
守卫Boss：天穹校准者。  
破坏结果：未来赫洛恩失去叙事上的绝对预判；正式战斗开始出现完整、可学习的攻击前摇，未来暴风雪出现安全窗口。

### 过去远征三：恒日熔炉

地点：赤砂盆地下方，与熔核深层连接。  
作用：为绝对时停与零时引擎提供持续能量。  
守卫Boss：恒日炉兽。  
破坏结果：未来赫洛恩无法永久停止整个战场；现代分布式能源技术出现，未来部分地区重新拥有昼夜变化。

三座装置的破坏是主线必经内容，不设计成互斥善恶选择。可选行动决定区域和NPC恢复程度，但不会让玩家因为完成主线而永久失去关键设施。

## 3.4 两次未来远征

### 未来远征一：确认灾难

玩家第一次进入毁灭后的未来，穿过叠时废墟并击败三相缝合体，取得剩余两座过去装置的坐标。随后遭遇未来赫洛恩并被第二次剧情秒杀，由时锚回溯到安全点。

这一远征的目标是：

- 让玩家亲自体验叠时灾变。
- 证明赫洛恩能够调用三个时代的装置恢复。
- 给出第二、第三次过去远征的明确方向。

### 未来远征二：终局

三座过去装置全部被破坏后，玩家第二次进入未来。

流程：

1. 在零时堡垒外层触发第三次赫洛恩遭遇。
2. 默认目标为坚持并通过岚打开的侧路撤离。
3. 高水平玩家可以留下并摧毁赫洛恩的外层战斗身体，迫使其意识退回核心，获得隐藏成就。
4. 玩家从侧路或Boss败退后进入堡垒内部。
5. 击败同步双子；两者分别控制一座堡垒门与一座应急稳定器，战斗胜利后同时关闭两个未来应急稳定器。
6. 进入零时引擎核心，进行第四次、正式且公平的最终战。

因此只需要两次主要未来远征，也能容纳第二、第三、第四次未来Boss相关遭遇。

## 3.5 历史节点数量控制

1.0最多设置六个会明显改变地图的历史节点。三个主线节点的Boss削弱和基础功能必定获得，但各自包含一次等价、非善恶的建设方向选择，让不同世界不只是完成度高低：

| 节点 | 类型 | 过去的行动 | 现代变化 | 未来结果 | 核心玩法奖励 |
|---|---|---|---|---|---|
| 1 时髓采集井 | 主线 | 摧毁续命核心并救出米卡；把修复资源投入“工匠学校”或“铁路集散站” | 两者都是繁荣矿镇；前者增加改造与家具，后者增加运输、商人和快速旅行 | 赫洛恩失去无限身体重构；未来矿道不再循环坍塌 | 两条路线都提供时锚门、米卡工坊和等值阶段装备 |
| 2 先见观测阵 | 主线 | 切断演算核心；把保存的数据交给“公共气象网”或“迁徙生态站” | 前者强化天气预报和通信，后者强化天空路线与生物资源 | 赫洛恩失去绝对预判；暴风雪出现可辨认安全窗口 | 两条路线都提供便携相位针；便利功能不同但战力等值 |
| 3 恒日熔炉 | 主线 | 摧毁时停供能核心；选择建设“分布锻造网”或“地热居民网” | 前者增加终局锻造分站，后者增加城镇能源、药剂和安全屋 | 赫洛恩失去永久全场时停；未来局部恢复昼夜 | 两条路线都提供完整相位罗盘与终局锻造权限 |
| 4 雾孢母树 | 可选 | 清除人工寄生层并恢复根系水源 | 湿林出现药材聚落和安全地表路线 | 未来出现未被机械孢群吞噬的绿色走廊 | 高级药剂、生命饰品、雾孢母巢残响 |
| 5 沉潮闸门 | 可选 | 修复旧水门和排水渠，不直接抽干整个湿地 | 现代形成可航行水道、码头商人和水下入口 | 被淹城市水位下降，开放堡垒侧路 | 水下呼吸、浮力装置、未来捷径 |
| 6 无名者档案钟 | 轻量 | 保存矿难名单、工作日志与钟楼机械 | 现代建立纪念钟与米卡个人支线 | 未来钟声成为幸存者导航时锚 | 复活点、音乐变化、家具与隐藏档案 |

状态控制：

- 三个主线节点一定完成核心目标，并各自记录A／B两种等价建设方向；选择不改变Boss削弱程度、主线权限或结局好坏。
- 每个A／B节点只生成一个不可复制、不可丢弃的“地区因果核心”。提交给任一建设方向后另一方向立即封存，普通挖矿、跨时代搬运和复制材料都不能同时完成两路。
- 未选择方向的核心战力、移动权限和主线制作站不会永久错过；其便利功能在下一阶段可用更高材料成本取得基础版本，但对应城镇外观、NPC分工和低成本优势只属于已选方向。
- A／B平衡按“到下一主线目标平均节省时间、提供的安全点数量、可取得战斗资源价值”三项测试；任一路在20名测试者中被选择超过75%时，先调整便利强度，不把明显最优解伪装成角色扮演选择。
- 两个可选节点使用“未完成／完成／完整修复”三档；一个轻量节点只使用“未完成／完成”两档。
- A／B方向只改变本地区域、两至三名相关NPC、便利功能和未来景观，不让所有NPC读取三项选择的全组合。
- 每个重大节点必须产生至少三项可观察变化；主线历史反馈间隔目标为3—5小时，其间用短支线、局部道路、天气和NPC日程变化提供1—2小时一次的小反馈。
- 米卡工坊属于节点1的必定结果，不会因为玩家漏掉隐蔽支线而永久错过武器改造与重铸功能。
- NPC对白只读取所在区域状态、主线阶段和少量个人标记，不读取所有节点的任意组合。

禁止制作几十个节点相互排列的全组合剧情，否则地图、对白、存档和测试都会失控。

### 沉潮闸门与水位实现边界

本作不模拟会跨整张世界连续传播的全局液体。沉潮闸门使用按区域保存的离散水位体积：淹没、正常、低水位三种预制边界，由历史节点结算一次切换，并重新验证入口、宝箱和玩家建筑冲突。玩家用桶、泵和方块改变的局部水格只属于当前时代与当前分块，不能排空整个湿林，也不能反向完成历史节点。被水位覆盖的玩家建筑使用防水时锚壳保留，容器内容不随水位生成或复制。

## 3.6 建筑保存

### 原生时代保存

- 玩家放置的方块、墙、家具、线路和容器带有玩家建造标记。
- 历史结算不会删除这些内容。
- 新时代覆盖层遇到玩家建筑时绕开玩家方块，并自动修复必要的自然支撑。

### 地标冲突处理

- 会变化的城镇在世界生成时预留一个主展示插槽和至少两个相邻备用插槽，而不是使用一整块不可移动模板。
- 玩家进入潜在历史展示区域时，地面显示可关闭的金色因果边界；允许继续建造，但界面会说明城镇结算时可能改用备用位置。
- 如果主插槽被玩家建筑占用，新城镇迁到最近的备用插槽，并自动生成一条可见道路、轨道或桥梁连接玩家基地，让历史变化仍能被玩家亲眼发现。
- 三个插槽都被占用时，核心商店与NPC进入公共时锚站，城镇主体进入相邻的可建设口袋区域；小型时间门只作为入口，不能用一扇门代替全部城镇变化。
- 结算预览会显示“城镇将在此生成／已迁往备用地标”，禁止结算后才告诉玩家主要反馈被隐藏。

### 时锚信标

- 初级：保护一定范围的建筑不受自然覆盖层影响。
- 中级：把基地轮廓投影到另一个时代。
- 高级：让指定储物箱跨时代共享。
- 终局：允许三个时代的同坐标基地形成完整联通。

跨时代投影是玩家主动选择，不自动把每一栋建筑复制三次。

共享储物箱在存档中只有一个容器ID，三个时代显示的是同一份库存，不复制物品。基地投影产生的装饰方块不能在其他时代拆除后获得第二份材料；只有将投影正式锚定并支付对应材料后，才转化为可拆除的实体建筑。

### 时间残响

被新历史替代的旧城镇、旧Boss和旧敌人进入时间残响副本。玩家仍能补图鉴、刷材料和重打Boss，不因改变历史永久失去内容。

时间残响不能只在结局突然出现。第一次矿镇历史结算后，岚就会带玩家进入一个小型残响房间，看见原废矿入口和老年米卡最初委托的中性记录。它不责怪玩家，也不提供第二份任务奖励，只用来证明“被覆盖的事件仍能被时锚保存”。最终的起源残响是同一规则的扩大应用，而不是结局临时发明的例外。

### 旧未来基地迁移

最终历史结算不会把玩家在灾变未来建设的基地留在被封存时间线中。结算事务按以下顺序处理：

1. 以玩家建造标记收集旧未来的实体方块、家具、线路、出生点和容器ID。
2. 优先迁移到新未来同坐标；与新地形冲突时整体平移到最近的预留基地插槽，并生成一座时锚门连接原坐标。
3. 实体容器和物品只存在于迁移后的新未来，保持原`container_id`与`item_instance_id`。
4. 起源残响只显示旧基地的半透明、不可拆除、不可存取投影，用来保存视觉记忆，不提供第二个箱子、制作站或出生点。
5. 迁移预览在摧毁零时引擎前显示；若验证失败则阻止最终提交并回滚，不允许静默删除建筑。

## 3.7 通关后的世界风貌修改

击败最终Boss后解锁“纪元编织台”：

- 每个已经完成历史节点的区域，可以选择一个已解锁的自然风貌。
- 选择只改变自然背景、天气、部分非关键敌人和地表覆盖，不删除玩家建筑。
- 关键NPC、制作功能和进度物品始终保留。
- 旧风貌继续存在于时间残响中。
- 未来层从纯废墟进入重建状态；旧灾变版本只通过分区时间残响和起源残响进入，不作为第四个会继续结算的世界层。

这提供通关后的沙盒目标，同时不增加第四条完整时间线。

## 3.8 三时代地图与变化界面

- 地图提供过去、现代、未来三个分页；当前时代使用实色，已访问的其他时代使用低饱和轮廓，未访问区域不提前泄露。
- 同一山峰、矿井入口、轨道和大型遗迹使用贯穿三个分页的地标编号，玩家可以一键对齐同一坐标。
- 金色波纹标记等待结算的历史节点；结算后只提示“该区域发生三处变化”，不直接把奖励和路线全部剧透。
- 玩家建筑、时锚门、安全落点、因果封锁边界和时间残响入口使用不同形状，同时配合颜色，不能只依赖红绿差异。
- 尝试同坐标穿越时，界面预览目标时代的可用落点；找不到安全位置时显示具体原因和最近安全点。
- 其他时代只显示玩家亲自探索过的区域；切换分页不会提前生成或泄露未访问洞穴。

## 3.9 世界不能只服务于赫洛恩

至少30%的探索地点、敌人、装备故事和可选任务必须来自独立于赫洛恩的生态、居民与旧文明。首发可选Boss裂年列车，以及盐沼沉船王、古矿脉之心两个精英事件，都必须拥有自身的地区冲突，不能被改写成赫洛恩的实验品。

每个生态区应同时提供：一个主线目的、一个当地居民问题、一个纯探索秘密和一个建筑资源理由。这样玩家进入区域不是只为了寻找下一座实验室，世界也不会像围绕Boss搭建的关卡走廊。

# 第四部分：战斗、装备、制作与建筑系统

## 4.1 无职业锁定

角色不在创建时选择职业。武器、护甲、饰品和召唤装置决定当前流派，玩家可以随时换装。

正式版的战斗资源分为：

- 体力：近战蓄力、格挡、冲刺和部分移动动作。
- 弹药：枪械与弓箭的消耗资源。
- 指令带宽：召唤无人机、炮塔与机械单位的容量。
- 时能：少量后期装备、相位能力和时间装置使用。

## 4.2 近战重点流派

| 流派 | 武器 | 特点 |
|---|---|---|
| 重装破势 | 巨剑、战锤、动力斧 | 慢速、高硬直、高破甲，可蓄力抵抗击退 |
| 迅捷连击 | 单手剑、双刃、链刃 | 冲刺、连段、流血和贴身闪避 |
| 长柄控制 | 长枪、戟、伸缩矛 | 控制距离、突刺、挑飞、对大型敌人稳定 |
| 盾反防守 | 剑盾、动力盾、护臂 | 格挡、精准反击、守住狭窄地形并保护任务NPC |
| 工程近战 | 钻枪、链锯、热能切割器 | 持续伤害、破坏装甲，与制作系统联动 |

近战数量和套装深度应高于其他路线，但不能让远程与召唤成为陪衬。

### 近战判定与受击基线

- 普通敌人不默认依靠身体重叠持续造成伤害；伤害来自带有起手、有效帧和收招的攻击判定。只有冲锋兽、滚动体和带刺外壳等明确轮廓敌人在对应状态拥有接触伤害。
- 玩家基础受击无敌时间以0.55秒为原型基线，同一攻击实体在一次有效帧中只能命中一次；多段招式必须有可读节奏，不能在贴身一帧内清空生命。
- 快速武器依靠位移取消和短无敌窗口维持贴身能力；重武器蓄力期间获得有限抗硬直而非完全无敌；长柄命中甜区与近身弱区必须通过特效表现。
- 盾牌普通格挡消耗体力并降低伤害，精准格挡窗口以0.12—0.18秒为原型基线，可打断非霸体普通敌人；Boss只能被削减架势或反射指定攻击，不能被无限硬直。
- 玩家受到连续攻击时最多被强制硬直一次，后续无敌帧内仍可移动或冲刺，禁止贴墙无限连。敌我碰撞框、攻击框和视觉刀光分别调试，刀光不能决定真实命中范围。

## 4.3 远程

### 枪械

- 直线弹道、后坐力、弹匣和换弹。
- 手枪、步枪、霰弹枪、重炮和特殊时晶枪。
- 不同弹药提供穿甲、爆裂、标记、减速和反机械效果。
- 装填是节奏设计，不做写实模拟。
- 普通弹药在解锁对应枪械后可由基础商人低价购买并用常见材料制作；特殊弹药保留材料决策，但不承担流派能否参战的门票。
- Boss第一次被召唤后，场地外出现只补充已解锁普通弹药的准备箱。玩家在Boss战死亡时返还本场消耗普通弹药的60%，最低保证下一次完整尝试所需的基础弹量；特殊弹药不返还，探索中也不存在无限免费补弹。
- 弓箭使用同一重试保护，但基础箭可在场地附近用木石制作；返还规则按发射时消耗计算，回收类词条不能与死亡返还叠加复制。

### 弓箭

- 蓄力、抛物线、特殊箭和地形利用。
- 更安静、材料更容易自制，适合探索与陷阱组合。
- 长弓、短弓、复合弓、弩与索敌箭装置。

枪械和弓箭共享部分饰品，但保持操作区别，不能只是不同外观的直线投射物。

## 4.4 现代化召唤

召唤路线不使用传统魔法宠物作为主要战力，核心单位包括：

- 侦察无人机。
- 近战护卫机器人。
- 自动炮塔。
- 维修蜂群。
- 轨道信标。
- 可切换攻击、防守、跟随与驻守模式的模块化机械。

玩家通过“指令带宽”控制总容量。召唤装备的重点是布置、目标优先级和模式切换，而不是单纯增加召唤数量。

召唤AI使用统一硬规则：

- 手动标记目标优先于正在攻击玩家的目标，再优先最近的可见敌人；目标死亡、离开活动区或遮挡超过2秒后重新索敌。
- 飞行无人机可越过小地形但不能穿过实体墙射击；地面单位寻路失败2秒或离玩家超过30格时，在玩家可见的安全位置相位回收并重放置。
- 召唤物不能挖掘、开箱、搬运物品、切换时代、启动因果机关、召唤Boss或改变NPC敌对状态。
- 玩家进入狭窄通道、城镇或高预警Boss阶段时，可以一键收束为跟随模式；透明度和伤害数字遵循第6.12.5节可读性设置。

## 4.5 时械辅助路线

时械不是独立魔法职业，而是可以与其他流派混合的工具：

- 短暂减速场。
- 延迟爆破标记。
- 伤害记录与一次回放。
- 投射物偏转。
- 小范围相位移动。

时械不能真正暂停正常Boss，也不能无限复制高伤害攻击。

## 4.6 装备获得

### 探索与制作

- 普通矿物负责基础装备。
- 生态区特殊材料负责流派特色。
- Boss核心解锁新制作站和一组装备。
- 不同年代的同类材料可以合成跨时代装备。

### Boss奖励

主线Boss首次击杀必定掉落：

- 每个世界一份关键核心。
- 至少一张新制作配方或制作站解锁。
- 一件保证可用的阶段奖励。

Boss不通过低概率掉落决定主线推进。随机武器用于增加重复挑战价值，但核心材料可以累积兑换目标装备。

主线关键核心拾取后立即写入世界进度账本并解锁对应制作权限；背包中的核心图标只是不可出售、不可丢弃的访问凭证，不作为会被配方永久消耗的普通材料。若物品因旧存档迁移或异常丢失，时间机器只能按原`item_instance_id`召回同一凭证；核心的`causal_anchor_id`与一次性发放标记保持不变，不能生成第二份核心或重复触发首杀奖励。

### 小怪稀有掉落

允许存在稀有武器和装饰，但需要满足至少一项：

- 达到一定击杀数后提高概率。
- 可以用同类材料制作。
- 图鉴完成后可向相关NPC兑换。

不能让一个核心流派因为1%掉落长期无法成形。

## 4.7 制作层级

1. 木石与废料工作台。
2. 现代机械台。
3. 过去时晶校准台。
4. 生态专用工作站。
5. 跨时代装配台。
6. 零时锻造核心。

制作配方优先使用少量有意义的材料，不用大量颜色不同但功能相同的碎片填充背包。

## 4.8 建筑与功能基地

基地功能包括：

- NPC居住。
- 制作与仓储。
- 时锚信标。
- 农场与药剂材料。
- 机械召唤物维护。
- Boss战准备和传送。

三个时代必须分别提供建造理由，不能让跨时代基地只剩视觉噱头：

- 过去：原生药材、因果工地和高纯度普通矿加工，适合农场与公共工程前哨。
- 现代：城镇NPC、完整商店、重铸、主要制作链和装饰收藏，是默认主基地时代。
- 未来：废墟打捞、残响研究、危险天气防护和终局材料精炼，适合防御与探索前哨。
- 时锚投影只提供共享仓储、返航点和基地轮廓；要启用某时代的专属功能，玩家仍需在该时代放置对应工作站并供能。

玩家可以为Boss修建战斗平台与机关。Boss通过移动模式、投射物和边界控制防止纯方块封死，而不是大面积摧毁玩家建筑。

Boss召唤前允许挖掘、搭平台、布线和装饰。Boss进入封锁状态后，竞技场结构范围内暂停放置、挖掘、倾倒液体和修改线路，已有平台继续生效；普通环境陷阱对Boss只造成受上限控制的辅助伤害，不能挂机击杀。战斗结束、玩家死亡或Boss脱战后立即解除冻结。封锁边界必须在召唤前可见，不能临时吞掉玩家建筑。

### NPC住房与跨时代安置

- 现代是可自由规划的主要城镇层；过去与未来NPC拥有各自时代的固定前哨，不会被玩家随意搬到另一个年代。
- 一个有效住房的首轮规则为至少7×5格内部空间、完整背景墙、可到达入口、光源、一件休息家具和该NPC需要的功能家具。
- 历史节点解锁的是NPC及职业资格，不会立刻把NPC传送进玩家家中；现代存在有效空房后，NPC在下一个白天搬入。
- 普通战斗中功能NPC生命归零时进入“重伤撤离”，从现场消失并在条件仍满足时于下一个安全白天返回，不在叙事上被随机怪物反复杀死。只有明确标识的历史节点和脚本事件可以记录永久死亡、失踪或未被救援；这类结果必须在确认前提示，不能由普通入侵随机触发。
- 基地投影不会复制NPC。投影时代只出现不能交易的时锚影像，实际NPC仍属于其原生时代与一个住房槽位。
- 关键NPC没有住房时会暂住公共时锚站，确保主线和制作功能不会因为玩家拆房而软锁。

### 货币、商店与米卡工坊

- 1.0只使用一种通用钱币，不再为三个时代各造一套货币；稀有制作依靠材料和Boss核心，而不是额外代币。
- 通用钱币是由时间机器登记价值、在时锚网络结算的“锚券”，不是三个时代恰好使用同一种铸币。未接入网络的过去居民仍通过任务材料和因果工地交换，不会无条件接受未来货币。
- 商店主要销售弹药、基础材料、建筑便利品、地图情报和已经解锁装备的替代取得方式，不直接出售超越当前阶段的毕业装。
- 同一商店库存与补货计时使用世界级ID，切换时代、进出残响和读档不刷新。商店回购价默认不高于售价的35%；可批量生产物、商店货与时代差价物拥有单独回购上限，禁止无风险跨时代倒卖生成无限锚券。
- 米卡工坊的“重铸”不是无限随机老虎机：每次展示三个明确候选模块，玩家选择其一或保留原属性；连续三次没有出现目标类别时保证至少出现一个对应类别。
- 重铸费用按装备阶段设上限，不能随失败无限增长；拆解同阶段装备可获得抵扣材料。
- 死亡掉落的钱袋保留到玩家再次死亡或主动放弃，并在地图显示；正常退出世界不会删除钱袋。
- 开场中央时间机器自带容量有限的“锚定零钱箱”，在玩家接触第一场Boss前完成银行安全教学；普通难度默认掉落50%随身锚券，宽松选项为25%，二者都不影响主线成就。

## 4.9 Boss公平性标准

正常Boss必须满足：

- 高伤害攻击有可辨认的视觉和音效前摇。
- 同类前摇与攻击结果保持一致。
- 不读取玩家按键。
- 不在最后一击无原因锁血。
- 近战、远程和召唤都至少有一种可靠应对方式。
- 不制造只能靠特定流派、随机稀有掉落或读攻略才能存活的必死机制。
- 重试路径短，召唤材料可重复制作或首次击败后变为低成本。

最终Boss在所有准备完成后仍保持高强度，依靠多阶段组合、场地变化和时间残影制造挑战，而不是依靠无法反应的秒杀。第三次隐藏战的困难来自装备阶段落后和撤离诱惑；第四战则拥有更多阶段、更完整的场地演出和机制组合，只是玩家已经取得正常应对工具，不能让它在观感与机制规模上像第三战的简单版。

### Boss战内的受控时代切换

因果封锁只禁止玩家从场外任意坐标传入、穿墙逃课或离开Boss房，不等于把核心时间能力从战斗中删除。至少四场完整Boss必须使用场内固定的“战斗时锚台”：

- 天穹校准者：在过去与现代观测台间切换，关闭不同方向的预测光束。
- 三相缝合体：同一Boss共享一条生命值，在三个时代形态间切换攻击和场地通路。
- 同步双子：玩家在两座固定时锚台间切换堡垒状态，打断两台应急稳定器的同步。
- 零时赫洛恩：过去破坏蓄力源、现代识别真实前摇、未来攻击连续性核心；每次切换都有固定落点和组合预告。

战斗时锚台切换的是零时引擎维持的局部场地覆盖，不会把玩家送回可修改世界历史的真实剧情日期，也不能接触Boss房外的NPC、资源与建筑。时锚台只在招式允许窗口点亮，切换演出不超过0.75秒并提供短暂落点保护；它不能清除Boss弹幕、重置冷却、重复触发消耗品或让玩家永久躲在另一个时代。Boss、场地机关和战斗计时使用同一个跨时代战斗ID，切换不会生成第二份Boss或首杀奖励。

# 第五部分：主线、Boss、NPC与任务

## 5.1 赫洛恩与叠时灾变

### 过去

30岁的赫洛恩是时晶研究员。他相信时晶可以延缓衰老、修复伤病，并建立时髓采集井、先见观测阵和恒日熔炉三个原型装置。

他在过去并不知道主角会击败自己。主角因相位噪声无法被普通人准确记住，只被赫洛恩视作破坏研究的无名入侵者。

### 现代

90岁的赫洛恩依靠时晶延续生命，并建立垄断时间技术的工业集团。未来的自己向他发送了一段极短的死亡信号：

- 信号中出现主角。
- 信号表明主角会终结他的连续存在。
- 信号没有准确时间、地点和完整战斗资料。

只有未来赫洛恩败亡时释放的能量足以发送这段信号，因此现代赫洛恩不能获得无限详细的未来攻略。

死亡信号抵达前，赫洛恩已经完成时晶续命、集团垄断和零时引擎原型论证；信号不是技术与灾难的自生起点。它只包含最后感知记录、主角的不稳定轮廓和连续体崩溃标记，促使现代赫洛恩把一个原本无关的探索者列为目标，并把本来谨慎推进的唯一历史计划加速为灾难。

从信号登记完成到最终核心毁灭，现代赫洛恩受到未来零时核心的“连续体回滚”保护。单纯摧毁其现代肉体只能让未来核心把状态回滚到最近锚点，不能终结三个时代共享的意识；三座过去装置被毁只会逐层削弱回滚质量，不会使保护提前消失。第一次现代遭遇必须用一次可见的受伤逆转和相位扫描结果向玩家证明这一规则。第三座装置被毁后，玩家拥有击伤现代赫洛恩的能力，但岚和扫描资料会明确说明：只有进入未来摧毁连续性核心，胜利才不会被回滚。

现代赫洛恩并非只受到死亡恐惧驱动。长期时晶实验让他保留了数次小规模历史改写前后的记忆，而普通人只记得最新人生。他逐渐认为：

- 可以被随意改写的人生不具备真实性。
- 每条被覆盖的历史都只是被多数人遗忘，并不等于从未存在。
- 只要时间仍可变化，任何关系、承诺和文明都可能被下一次改写抹去。

这个观察有一部分真实，但他的解决方式是规定唯一合法历史，并确保这条历史由自己统治且永远抵达不了自己的死亡。

现代赫洛恩试图提前消灭主角，反而迫使原本只想修复时间机器的主角加入事件，形成闭环。主角每破坏一座过去装置，赫洛恩都会新增一组彼此冲突的记忆，使他的言行和外观进一步失去稳定。

### 未来

赫洛恩认为，只有把世界固定为唯一版本，所有人的人生才不会再被改写；同时，他选择的唯一版本必然停在自己死亡之前。他启动零时引擎，将自己同时锚定在过去、现代和未来。

零时引擎失控后发生“叠时灾变”：

- 地区在不同年龄之间跳变。
- 古代生态与未来机械互相侵入。
- 生物反复衰老、幼化和复原。
- 同一建筑的不同时代版本重叠。
- 世界部分区域停留在同一天。
- 赫洛恩必须持续吸收时间能源维持存在。

灾难不是Boss释放的一次爆炸，而是他强迫所有时代服从同一个“正确版本”后，世界长期承受的状态。

主题对立：

- 赫洛恩：只有不再变化的唯一历史才是真实，个人选择只会制造更多被覆盖的人生。
- 主角：稳定不能以剥夺所有未来为代价；即使赫洛恩注定被击败，谁能活到胜利、世界以什么样子继续存在仍由行动决定。

## 5.2 主要角色

### 主角

- 完全自定义名字、性别表达与外观。
- 开场身份只规定为接受矿区委托的自由探索者，不规定出身、家庭和固定性格，既能解释挖掘建造能力，也给玩家保留角色扮演空间。
- 不设置固定配音和大量内心独白。
- 性格通过少量语气选项与实际完成的行动表达。
- 穿越到非原生时代时带有相位噪声，普通人无法准确记住其面貌。
- 角色外观采用一套共用骨骼、碰撞体和动作时长，身体轮廓、肤色、发型、面部与配色分层组合；性别表达不建立第二套战斗动画和装备数值。
- 护甲按约六种可复用轮廓族制作，头部、躯干、腿部和背饰分层；武器、枪械、盾牌与召唤控制器使用独立挂点。每件装备不为不同性别重新绘制全套逐帧动画，避免自定义角色把美术量翻倍。

### 岚，未来返航者

- 岚是同一个角色的男性／女性表现版本，名字、经历、性格、任务、能力和剧情地位完全相同。
- 男性主角默认遇见女性岚，女性主角默认遇见男性岚；主角选择非二元、未指定或自定义性别时，在建档时选择男性岚、女性岚或随机。
- 建档界面提供“岚的性别呈现：自动／男性／女性”，玩家可以覆盖默认对应关系，避免把角色关系强制限定为异性组合。
- 岚的版本在世界首次创建后固定；修改主角外观或性别表达不会让岚中途变化。
- 两个版本只分别制作角色身体与头像差异，共用装备、动作时长、碰撞、任务和对白语义；本作不做全对白配音，因此无需维护两套录音预算。
- 原本是未来城市的时序设施测绘员，不是抵抗军领袖或传奇战士。
- 在维护废弃中继站时截获赫洛恩的死亡信号，利用工作知识从灾变未来回到现代，请求主角帮助。
- 时间机器受损，只能先利用现代废矿中的时晶恢复。
- 不是全知任务发布器；只掌握未来废墟、死亡信号和少量历史残片。
- 每次历史改写后仍保留旧记忆，但身体会出现轻微相位不稳定，为角色关系提供代价而不是强制背叛。
- 岚不做全程实体跟随AI：平时驻守时间机器或已解锁时锚，通过玩家主动呼叫的短讯提供提示；只在少数脚本化场景和终局战中作为不会抢夺伤害归属的支援角色，避免寻路、卡门和护送拖累沙盒探索。
- 非主线紧急事件中，岚的主动通讯间隔不少于8分钟；重复进入区域不反复播报，玩家可以在日志中重听或关闭非关键提示。
- 岚与主角默认是共同承担闭环的搭档。终章可以确认“战友／挚友／伴侣”，三种关系不改变战斗、商店、成就与世界恢复程度；1.0不制作送礼、约会和好感刷取系统。
- 世界存档保存玩家选择的尾声关系；三种关系只有对白与镜头差异，不改变奖励、功能或结局评级。
- “伴侣”不是终章突然出现的无条件按钮。主线中设置三个可选的锚点共鸣场景：第一次矿镇改写后谈论陌生的新记忆、第一次未来远征后处理岚的相位失稳、最终远征前决定彼此是否共同承担旧未来记忆。场景只选择回应语气，不显示好感数值。
- 战友始终可选；完整观看任意两个共鸣场景后开放挚友；三个场景中至少两次选择明确亲密回应才开放伴侣。未开放选项显示其叙事条件但不绑定奖励、属性或成就，避免玩家为战力被迫恋爱。

### 米卡，矿区NPC

- 过去约8岁，现代约68岁。
- 原历史中是住在废矿的拾荒老人。
- 游戏开场由原历史中的老年米卡委托主角进入废矿寻找一枚旧动力核心，主角因此发现岚和时间机器。
- 主角在过去必定救他脱离一次坍塌；额外行动决定他后来成为普通矿工、镇长还是机械大师。
- 历史改写后，米卡不再记得自己曾以拾荒老人身份委托主角，只拥有新人生记忆，但会因主角携带的时间钥匙声响和动作产生熟悉感。
- 他说“你让我想起六十年前的一个人”，不直接识破主角身份。

### 祁安，现代时序调查员

- 原本负责调查赫洛恩集团的矿难、非法实验和能源垄断，没有时间旅行能力，也不是突然出现的救世组织领袖。
- 第一章结尾来到改写后的矿镇核对档案；第二章向主角提供进入集团观测站的合法掩护，并保存玩家取得的设备日志。
- 三个主线节点提供的矿难档案、公共气象资料和分布式能源蓝图逐步组成公开证据，同时让现代城镇获得脱离集团控制的实际基础设施。
- 终章的“时序审判机构”由祁安、受影响城镇和独立工程师组成的调查联盟改组而来，因此现代赫洛恩被隔离不是结局临时生成的方便手段。
- 祁安只负责现代政治与证据线，不解释时间闭环，不取代岚的搭档地位。

### 其余城镇功能NPC

1. 基础商人：弹药、绳索、火把和回收服务，开局即可入住。
2. 湿林药师：药剂、抗性和雾孢节点支线，只读取湿林状态。
3. 铁路测绘员：地图标记、矿车与裂年列车入口，只读取矿镇建设方向和赤砂阶段。
4. 天穹工程师：滑翔、无人机模块和天空路线，只读取观测阵方向。
5. 档案保管员：图鉴、掉落记录和无名者档案钟支线，只读取档案节点。

连同主角之外的岚、米卡、祁安和赫洛恩，城镇与剧情常驻角色控制在8—10名。每名功能NPC只有一个本地区域弧线和一套商店升级，不为六个节点的全组合撰写独立人生。

### 赫洛恩

- 不是三个独立Boss，而是同一个人在三个时代的连续变化。
- 过去仍保留理想主义与人性，现代被恐惧和控制欲支配，未来成为零时引擎的一部分。
- 他的失败是固定点，但失败发生时世界还剩下什么不是固定的。

## 5.3 主线章节

### 序章：废矿中的时核

1. 原历史中的老年米卡委托主角进入废弃矿区寻找旧动力核心。
2. 主角在矿区发现刚刚坠落现代的岚与受损时间机器。
3. 受损机器失控投射约25秒“未来回声”：同一矿井被叠时风暴撕裂，远处城市轮廓重叠，岚的身体开始相位崩解。画面不出现责怪主角的记录或旁白。
4. 击败错时掘进机，取得未校准时核。
5. 主角已经亲眼确认灾难和岚的处境，主动修复时间机器并第一次进入过去。

### 第一章：矿镇与第一装置

1. 在过去看见繁荣矿镇。
2. 救出年幼米卡。
3. 击败时髓巨虫。
4. 摧毁时髓采集井。
5. 返回现代，看到废矿变成不同程度的存续城镇。
6. 与只记得新人生、却觉得主角熟悉的米卡重逢，并解锁米卡工坊的武器改造与重铸。
7. 岚开启第一个小型时间残响，让玩家看见原废矿入口与最初委托记录，提前建立残响保存旧事件的规则。

### 第二章：现代的追杀

1. 赫洛恩察觉旧历史被改写。
2. 玩家与祁安接触，保存矿难证据，并探索现代林海、盐沼和集团设施。
3. 击败阻断湿林路线的雾孢母巢，取得防污染材料并开放集团观测站侧路。
4. 祁安提供观测站掩护，玩家第一次直接遭遇赫洛恩。
5. 触发约15秒绝对停滞剧情击杀，由岚紧急回溯；不显示失败结算，不消耗资源。
6. 玩家带回观测站密钥并解锁第一个未来坐标，第一次遭遇仍产生明确进展。

### 第三章：第一次未来远征

1. 进入叠时废墟。
2. 击败三相缝合体。
3. 找到先见观测阵与恒日熔炉的历史坐标。
4. 第二次遭遇赫洛恩，在60秒生存中完成扫描和坐标上传；界面先显示“数据上传完成／任务成功”，随后才被终末校准击杀。
5. 回溯至现代后保留全部扫描资料、坐标和一次永久的相位扫描升级，开始准备剩余过去远征。该段的叙事结果是任务成功，不是第二次战斗失败。

### 第四章：被改变的观测院

1. 探索现代雪原和天空设施。
2. 第二次主要进入过去。
3. 击败天穹校准者。
4. 摧毁先见观测阵。
5. 返回现代，观察天气、通信与相关NPC历史变化。

### 第五章：恒日熔炉

1. 探索赤砂铁路与熔核深层。
2. 第三次主要进入过去。
3. 击败恒日炉兽。
4. 摧毁恒日熔炉。
5. 获得相位罗盘和进入零时裂境的能力。

### 第六章：第二次未来远征

1. 进入零时堡垒。
2. 第三次遭遇赫洛恩：默认撤离、高手可胜。
3. 通过堡垒侧路抵达两台未来应急稳定器的联动控制区。
4. 击败分别控制一台稳定器的同步双子，战斗结束时同时关闭两台设备。
5. 进入核心进行第四次正式决战。
6. 赫洛恩败亡触发不可取消的自动死亡协议；警告发送完成后，玩家主动摧毁零时引擎，岚用返航锚把两人送回现代，旧闭环开始封存。

### 终章：时间继续

1. 玩家在现代见证最终历史结算；新未来坐标稳定后，与岚共同进入不再重复叠时灾变的新未来，旧灾变未来只存在于起源残响。
2. 岚以“因果唯一体”继续存在；节点完成度改变其参与的重建地点和结局镜头，不决定其是否被抹除。
3. 玩家根据已经完成的锚点共鸣场景确认岚与主角的尾声关系：战友、挚友或伴侣。三项都不影响功能、奖励与世界结局，未满足叙事条件的关系不会突然开放。
4. 解锁纪元编织台、残响Boss和纪元漫游模式。

## 5.4 赫洛恩四次遭遇

| 次数 | 地点 | 形式 | 玩家目标 | 结果 |
|---|---|---|---|---|
| 第一次 | 现代时间观测站 | 约15秒剧情遭遇 | 在时间冻结中移动并理解差距 | 被绝对停滞击杀，快照回溯 |
| 第二次 | 第一次未来远征 | 约60秒生存／扫描 | 完成扫描与上传；攻击用于揭露弱点并加快上传，不用于击杀 | 先显示任务成功，再被终末校准击杀；保留坐标与相位扫描升级 |
| 第三次 | 第二次未来远征外层 | 赫洛恩的远程战斗体；完整高难战斗 | 默认坚持90秒后撤离；高手可在开门前击败，或开门后留下继续战斗 | 逃离则正常推进；获胜可摧毁外层身体并解锁隐藏成就 |
| 第四次 | 零时引擎核心 | 本体意识与连续性核心；正式最终Boss | 运用全部时代装备与已学规则取胜 | 自动死亡协议发送完成后摧毁零时引擎，终结闭环 |

第三次的血条只代表赫洛恩投射到堡垒外层的战斗身体，不代表零时引擎中的跨时代意识。清空血条是真实胜利而不是锁血假战，但赫洛恩会把意识撤回核心，因此第四次战斗仍然必要。界面、掉落说明和岚的对白必须在第三战后明确这一点。

## 5.5 第三次隐藏成就

推荐名称：

**不在记录中的胜利**

隐藏描述：

**在历史允许你获胜之前，迫使赫洛恩败退。**

规则：

1. 第三次遭遇开始后，正常目标是坚持90秒。
2. Boss从第一秒就拥有完整生命值并可被正常伤害；高水平玩家可以在90秒前击败它。
3. 90秒后侧路开启，玩家可以撤离，也可以留下；开门只改变出口，不改变Boss血量和阶段。
4. 选择留下时保留当前Boss血量，撤离门关闭，Boss不回血、不锁血，也不追加只能靠隐藏装备应对的新招。
5. Boss全部攻击均可躲避，不使用锁血、输入读取或不可避免秒杀。
6. Boss强度比当前推荐装备高一个阶段，但不依赖随机获得的唯一装备。
7. 清空血条后，Boss的外层战斗身体破碎，被迫退入零时核心；这不是最终固定点。
8. 奖励为Steam隐藏成就、称号、时装、断裂钟针家具和特殊残影，不掉落碾压最终战的武器。

避免永久错过：

- 第一次逃离或失败后，外层留下“未定残响”。
- 玩家可以在推进最终核心前随时重试。
- 通关后仍可通过残响重试，但挑战会启用该章节的装备同步上限，禁止用终局装备碾压。
- 如果玩家在第四战前取得成就，最终赫洛恩面具带有裂痕，拥有专属开场对白和一招替换技能；总难度不额外提高。
- 如果通关后才取得成就，可以通过最终Boss残响观看对应版本。

选择规则：

- 90秒撤离门开启时只显示“撤离”与“继续战斗”，不提前公开隐藏成就。
- 选择继续后撤离门关闭，本轮只能击败Boss或失败回溯；菜单暂停仍可使用。
- 残响重试沿用相同装备同步上限和撤离规则，不能靠通关后的数值压制替代学习。

这样既保留高手成就，也不逼全收集玩家备份存档。

## 5.6 自定义主角的人物变化

不使用固定内心独白宣布主角“现在已经成长”。变化通过游戏行为呈现：

- 开局目标只是修复时间机器和解决现代威胁。
- 废矿中的短暂未来回声让主角在第一次穿越前亲眼看见灾难，但不通过预言宣布主角是救世主。
- 第一次历史改写后，玩家看到米卡拥有一段全新人生。
- 三个主线节点要求玩家在两种等价建设方向中选择自己希望留下的世界形态；这些选择表达价值倾向，但不评价善恶，也不改变Boss削弱程度。
- 中期出现不阻挡主线的救援、净化和历史调查任务。
- 完成这些任务会带来城镇、NPC与未来重建变化。
- 米卡、祁安和岚只根据玩家实际做过的本地区域行动作出简短回应，例如“你总会为后来的人留一条路”，不替自定义主角宣告固定情绪或人格。
- 结局根据实际世界状态生成，而不是由最后一个善恶按钮决定。

对话选择只表达语气，例如谨慎、直接、关心或沉默，不建立会指数增加对白的复杂人格系统。

## 5.7 掉落物叙事

主线信息必须100%获得：

- Boss核心说明。
- 装置记录。
- 必经房间中的影像或终端。
- 岚与赫洛恩的关键对话。

小怪与装备负责补充：

- 矿工和居民的日常生活。
- 集团制度与实验伦理。
- 同一装备在三个时代的磨损和改造。
- 被改写人物留下的模糊痕迹。

稀有掉落只承载可选考据，不承载“Boss为什么制造灾难”这类理解主线所必需的信息。

## 5.8 终局人物状态

| 人物／时代 | 最终状态 | 解决的逻辑问题 |
|---|---|---|
| 过去赫洛恩 | 仍作为30岁的研究员存在；三装置被破坏后的新历史会让他走向能力受限的现代版本 | 保留人物连续性，又不要求新未来重复旧灾变 |
| 现代赫洛恩 | 未来意识回流被切断，失去时间能力与集团垄断，被时序审判机构隔离；余生无法接触时晶网络，之后按正常寿命在新未来形成前去世 | 玩家通关后回到现代不会再次面对完整Boss，也无法靠原资源重建零时引擎；新未来不存在另一个130岁时间连续体 |
| 旧未来赫洛恩 | 零时连续体和肉体彻底终结；毁灭前已经发出死亡警告，战斗记录封存为起源残响 | 给现代警告提供永久来源并完成Boss必败闭环 |
| 新未来 | 从最终历史结算后的现代继续发展，不再自然生成第二个赫洛恩或叠时灾变 | 解释闭环为什么不会无限重演 |
| 岚（男性／女性版本） | 作为“因果唯一体”保留，不会在重写后的未来再生成第二个岚；性别版本保持建档选择 | 避免同一人物出现复制人或中途变换版本 |
| 米卡 | 保留新历史中的完整人生，只对主角产生模糊熟悉感 | 展示普通人不记得旧历史 |
| 祁安与调查联盟 | 利用三次主线保存的证据和替代基础设施，改组为时序审判机构并接管时晶网络 | 让现代赫洛恩的隔离与集团瓦解拥有前期人物、证据和执行力量 |
| 主角 | 保留所有历史记忆与自由穿越能力 | 支撑通关后沙盒玩法 |

最终战摧毁的是赫洛恩横跨三个时代的共享意识与零时引擎，不是反向杀死年轻版本。死亡警告和最终战在核心毁灭前已经发生并写入时锚记录层，所以现代追杀、主角穿越和最终战都有来源；最后结算只改写它们之后的新未来。

因果唯一体规则：

- 主角和岚不会在新历史中产生第二个自己。
- 新未来会自然形成他们缺席后的社会关系，不生成一个等待与旧版本合并的复制人。
- 通关后岚可以选择继续保留旧未来记忆；不把自我消失设为唯一正确结局。

敌人“变体”必须改变至少一种行为、移动方式或攻击组合，不能只改颜色和生命值。

48套敌人配置按以下方式生产：六个生态区各四种基础敌人，共24种；另有4种跨生态叠时异常体、14种行为变体和6种精英事件。每个生态区的四种基础敌人至少覆盖“接近压迫、远程预警、地形移动、支援／控制”四个角色，不能全部是朝玩家直线移动的不同血量单位。

约126件功能装备的首轮分配为：20件近战武器、8把枪械、6把弓弩、8个召唤控制器、9套三件式护甲共27件、24件饰品、15件工具／时间装置、18件药剂与功能建造物。单纯换颜色、只增加小数值或没有新配方价值的物品不计入功能装备；缺少人日时优先删除重复品，不降低每个流派在六阶段的可通关性。

## 6.3 前两小时垂直切片

垂直切片完整制作现代与过去，并额外制作一个只覆盖矿井入口、约6—8分钟的可操作未来残片。它不提前生产完整未来生态，但必须验证玩家能在同一坐标辨认并操作三个时代，并完成一次真正依赖时代切换的短战斗。

这个未来残片是受损时间机器从岚的返航尾迹中重建的局部交互投影，不是提前解锁完整未来坐标：玩家不能离开矿井边界、开采实体资源、放置永久建筑或把投影敌人的掉落带回主世界。它使用正式时代切换、落点检查、分块覆盖和跨时代战斗ID代码，完成后只登记一份记录奖励；因此既能验证三时代技术与路线玩法，又不会破坏第一章的成长和资源顺序。

### 内容

- 一个基础生态区：绿脊丘陵与矿区。
- 两个时代层：现代废矿、过去矿镇。
- 四名主要NPC：岚、米卡、祁安和一名基础商人；男性／女性岚共用任务和功能数据。
- 八种普通敌人，其中三种拥有时代差异；未来残片复用一套敌人骨架制作一个60—90秒的叠时精英“错相追猎者”。
- 两个完整Boss：错时掘进机、时髓巨虫。
- 二十四至三十件可用武器、工具、护甲与建造物，但主线只主动教学10—14件，其余通过探索、配方和图鉴自行发现。
- 一座基础时间机器。
- 一个拥有原历史状态和两种等价建设结算方向的矿镇历史节点。
- 一个连接过去、现代和未来残片的固定薄弱点谜题与短战斗：过去形态破坏追猎者的生体甲壳，现代形态切断锁定模块，未来形态才能伤害不稳定核心；三形态共享生命和战斗ID，只需切换2—4次，不掉落可带回主世界的资源。
- 玩家建筑保存与历史覆盖的最小实现。

### 时间安排

| 游玩时间 | 内容 |
|---|---|
| 0—10分钟 | 移动、挖掘、建造、遇见岚，并亲眼看见约25秒未来回声 |
| 10—30分钟 | 自由探索现代废矿、救援NPC、取得三个不同来源的时核组件 |
| 30—45分钟 | 击败错时掘进机，完成第一次穿越 |
| 45—70分钟 | 识别过去矿镇与现代废矿的对应关系 |
| 70—95分钟 | 救出米卡、击败时髓巨虫、破坏第一装置并选择矿镇建设方向 |
| 95—100分钟 | 结算并返回现代 |
| 100—110分钟 | 回访变化后的城镇，与米卡和祁安重逢，完成一次武器改造 |
| 110—120分钟 | 进入首个小型残响，在固定薄弱点完成一次过去／现代／未来残片路线谜题，并击败60—90秒的错相追猎者 |

### 成功标准

测试玩家应当能够：

- 在60分钟左右完成第一次穿越，而不是先刷数小时材料。
- 不依赖长篇文字，能够说明“未来会发生时代重叠灾难，岚正在被其影响”。
- 不看说明文字也能认出至少三个跨时代相同地标。
- 在未来残片中主动使用三时代差异通过一条路线，而不把未来理解成只能观看的过场。
- 在不阅读长说明的情况下，说出错相追猎者至少两个时代形态的不同处理方式。
- 返回现代后主动说出至少三项世界变化。
- 理解玩家建筑没有被删除。
- 理解普通NPC只记得新历史。
- 理解被覆盖的旧事件只存在于只读残响中，不会与新城镇同时结算。
- 愿意继续探索下一次变化，而不是只关心数值奖励。

如果这段不成立，不继续扩建六个生态区。

## 6.4 开发里程碑

开发里程碑按两名全职成员计算。时间是规划区间，不是发行承诺；每个阶段结束后根据实际燃尽速度重新估算。

### 里程碑A：核心技术原型（约4—6个月）

- 挖掘、放置、存档。
- 基础随机世界。
- 两个共享骨架的时代层。
- 同坐标安全穿越。
- 玩家方块标记和历史覆盖避让。
- 单人战斗与一个测试Boss。

### 里程碑B：两小时垂直切片（追加约5—8个月）

- 完成第一个历史闭环。
- 完成两名Boss、四名NPC、矿镇两种等价建设方向和一个6—8分钟可操作未来残片；男性／女性岚共享任务与功能数据。
- 完成基础近战、枪械、弓箭与无人机各一套。
- 完成第一次外部玩家测试。

### 里程碑C：内容Alpha（追加约10—16个月）

- 六个基础生态区骨架。
- 三次过去远征和第一次未来远征。
- 全部主线Boss灰盒完成。
- 核心装备成长和NPC功能完成。

### 里程碑D：内容Beta（追加约7—10个月）

- 第二次未来远征、最终Boss和通关后模式。
- 所有历史节点。
- 可选Boss、残响挑战和隐藏成就。
- 性能、存档、崩溃恢复与辅助功能测试。

### 里程碑E：Steam发布准备（追加约3—5个月）

- 成就、云存档、商店页面与发布构建。
- 键鼠和手柄完整适配。
- 色盲标记、减少闪光、减少屏幕震动、可调文字速度。
- 多语言文本结构和崩溃恢复。

上述里程碑顺序相加为29—45个月，约2.4—3.8年。GPT提高局部效率后仍应保留这个范围，因为世界状态、存档迁移、Boss手感、美术和内容返工无法按生成文本的速度完成。若两人是业余时间开发，应先把目标改成付费序章或大幅继续减量，不能沿用上述工期。

Steam页面建议在里程碑B完成、已有可录制的真实游戏画面后再公开。Steam Playtest建议在里程碑C中期开始。抢先体验只应在里程碑C完成、已有至少10—12小时稳定内容并能够保证旧存档迁移时考虑，不把抢先体验当作替代开发资金和测试的捷径。

## 6.5 当前必须避免的错误

1. **把两次剧情秒杀包装成正常Boss战。** 必须提前冻结消耗品状态，目标清晰，时间短，并完整恢复资源。
2. **让第三次隐藏胜利永久错过。** 使用未定残响和装备同步保留公平重试。
3. **第三次获胜对第四次毫无反应。** 至少改变Boss外观、开场对白、音乐引子和一招等价替换技能。
4. **让自定义主角说大量固定情绪台词。** 用行动、世界结果和轻量语气选择表达。
5. **历史状态任意组合。** 限制为六节点；三个主线节点各有A／B等价方向，其他节点最多三状态，并只按所在区域读取对白。
6. **三个时代独立随机生成。** 必须共享种子、骨架、地标插槽和视觉锚点。
7. **主线不停制造紧急倒计时。** 沙盒阶段明确告诉玩家时间机器已经稳定，可以自由准备。
8. **每次穿越都要求回唯一机器或重复刷燃料。** 用永久升级、时锚门、返航器和相位罗盘逐步放开。
9. **玩家准备充分后最终Boss失去压力。** 移除的是不可反应的规则，不是Boss的正常伤害、阶段和组合深度。
10. **历史改写删除建筑或绝版内容。** 玩家方块受保护，旧内容进入时间残响。
11. **关键剧情依赖低概率掉落。** 主线信息必定获得，稀有掉落只用于考据。
12. **删除联机后重新扩张内容。** 省下的网络与联机测试工期必须投入手感、存档和历史反馈，不能换回更多Boss与生态区。
13. **Boss变体只增加血量。** 每个时代形态需要改变行为和战斗节奏。
14. **用故事设定替Boss作弊。** “预测未来”通过动画前摇、假动作和延迟攻击表现，不能读取输入。
15. **因为有GPT就重新膨胀到v0.1规模。** GPT能缩短样板代码和草稿时间，不能自动完成手感、美术一致性、存档测试与关卡验证；1.0上限为10套完整Boss配置和48套常规敌人／变体／精英配置。
16. **把岚的性别版本做成两套性格，或默认强制恋爱。** 男性／女性岚必须共用人物核心、任务和能力；自动对应关系可以在建档时覆盖，尾声关系由玩家确认且不绑定奖励。
17. **让最终胜利继续要求现代赫洛恩必然变成未来Boss。** 死亡信号与最终战必须封存为起源残响，零时引擎毁灭后新未来才能真正脱离循环。
18. **允许玩家在三个时代重复开采同一批终局矿物。** 普通资源可以时代独立，高价值因果矿脉必须共享枯竭ID。
19. **第三战清空血条后不解释为什么还有第四战。** 第三战明确摧毁远程战斗身体，第四战才摧毁本体意识与零时引擎。
20. **把“内容上限”当成必须填满的清单。** 垂直切片的真实中位工时高于预算25%时必须执行减量阀门，不用低质量换数量。
21. **把岚做成全程跟随宠物。** 沙盒寻路、传送和挖洞会让实体跟随频繁卡住；岚只在时锚提供短讯与脚本化支援。
22. **允许角色跨世界携带装备。** 这会跳过Boss与历史节点并制造复制问题；只允许复用外观预设。
23. **把“主角看见过”当成时锚注册。** 只有获得`causal_anchor_id`的对象能够跨结算保留身份或事件来源；普通观察不能制造残响实体。
24. **用无限因果补偿修剧情。** 三层应急锚储备用尽后不能再补偿，也不能用补偿复活NPC或恢复装置。
25. **宣传三时代，垂直切片却只让玩家操作两个时代。** 前两小时必须包含一个可操作未来残片和一次三时代路线谜题。
26. **Boss房完全禁用时间能力。** 禁止的是场外传送逃课；关键Boss必须通过固定时锚台使用受控时代切换。
27. **保护建筑却把历史变化藏进一扇门。** 城镇改用备用插槽时必须生成可见道路和完整新区域，不能牺牲核心反馈。
28. **把物品唯一ID和因果锚ID混成一个字段。** 普通制作物使用`item_instance_id`，只有身份与剧情来源使用`causal_anchor_id`；否则终局后无法继续制作并穿越。
29. **让赫洛恩明知警告制造主角却毫无理由继续发送。** 死亡警告是维持连续体的自动协议，也是他不敢拆除的自保凭证，不是结尾临时按键。
30. **不解释为什么玩家不能在现代提前杀死赫洛恩。** 未来核心毁灭前，现代肉体会被连续体回滚；游戏必须用可见演出证明，而不是只靠设定集。
31. **通关时无提示封存未完成历史节点。** 终局门必须列出节点结果并允许取消，残响补内容不能偷偷合并回主世界。
32. **让挖掘和建筑无意绕过主线。** 关键结构使用可见强化等级，Boss战中冻结场地修改，策划支持的捷径必须主动标识和测试。
33. **让普通怪物随机杀死重要NPC，再用复活淡化历史救援。** 普通战斗只造成重伤撤离，永久人物结果只由明确历史节点记录。
34. **所有近战敌人都靠身体重叠伤害。** 接触伤害只属于明确状态；其他敌人必须使用有起手和有效帧的攻击判定。
35. **把两个完整Boss、三时代规则和二十多件物品全部做成强制教学。** 前两小时只主动教学10—14件物品，其余留给探索；核心时间战斗由一个短精英证明。

## 6.6 已锁定的产品与范围决定

### 模式

- 1.0为纯单人游戏，不预留在线合作、本地分屏、PvP、专用服务器或公开匹配功能。
- 不把联机写进商店路线图，也不先维护一套未使用的网络抽象；未来若重新立项，按独立资料片级项目评估。
- 删除联机不改变1.0内容上限，优先保证单人手感、读盘、历史结算和Boss可读性。

### 难度

- 1.0只平衡一套标准主线难度，不另外制作拥有独立AI和独立掉落的专家世界。
- 提供降低屏幕闪光、镜头震动、受伤数字密度、按键连打要求等辅助选项。
- 普通死亡默认掉落50%随身金钱；可在建档时选择25%的宽松掉钱，不影响主线成就。
- 高难内容集中在残响Boss、无伤记录、限时挑战和第三次赫洛恩隐藏胜利，使用固定规则便于公平比较。

### 世界与存档

- 1.0只提供一个标准世界尺寸：宽6144格、高1536格。
- 世界按64×64格分块，每个时代共享基础种子，但拥有独立覆盖和玩家改动记录。
- 地形按需生成；存档主要保存种子、历史节点、玩家修改和容器，而不是重复保存三张完整地图。
- 目标是50小时世界存档压缩后低于100MB，自动保存时主线程可感知停顿低于100毫秒。
- 每次历史结算前保留一个备份，循环保留最近5个本地备份；Steam Cloud是同步手段，不是唯一备份。
- 外观预设可以跨世界复用，角色装备和任务进度绑定世界；复制世界会生成新的世界ID，避免云存档覆盖原档。

### 美术和显示

- 像素美术；逻辑格为16×16像素。
- 内部参考分辨率640×360，使用整数缩放适配1080p及更高分辨率。
- 角色基础画布约24×40像素，大型Boss允许使用多部件骨骼与特效组合，避免全部逐帧绘制。
- 三个时代共享轮廓、动画骨架和基础材质，通过覆盖层、配色、附加部件和特效形成差异，不能为每个时代重画全部资产。

### 发行

- 首发正式支持Windows x64。
- Steam Deck和Proton只有在真机完成性能、字体、手柄和云存档测试后才标注支持。
- 首发语言为简体中文和英文；英文可以用GPT生成初稿，但必须人工通读并在真机UI中检查。
- 1.0不做创意工坊和官方模组API，数据表保持可扩展，为后续版本预留。

### 音频

- 不做全对白配音，避免三时代状态与后续文本修改导致录音量失控。
- 六个生态区使用共享主题加过去／现代／未来分层乐器，不为十八种时代覆盖分别写完整曲目。
- 普通武器与环境音优先建立可组合的音效素材库；购买或外包素材必须保存授权凭证。
- 最终Boss和隐藏第三战可以共享主题动机，但节奏、配器和结尾不同。

### 1.0明确不做

- 不做三个时代的任意方块逐格历史传播，也不模拟建筑自然老化六十年。
- 不做全世界连续液体物理、可编程电路、自动化工业链和大型载具建造。
- 不做钓鱼、坐骑繁育、NPC恋爱养成、城镇人口模拟和随机生成主线对白。
- 不做在线／本地多人、跨世界装备携带、拍卖行与长期赛季服务。
- 不为每种历史组合制作独立结局；结局由六个节点的分组结果和少量关键镜头组合生成。

这些不是“以后一定补”的宣传承诺，而是保证两人团队能把挖掘、战斗、穿越、建筑保存和单人存档做稳的范围边界。

## 6.7 技术方案

### 引擎与语言

- 固定使用Godot 4.7.1稳定版.NET和C#。
- 项目开始后不跟随每个Godot小版本自动升级；只在独立升级分支完成存档、渲染、输入和性能回归后合并。
- 生产代码统一使用C#，不同时维护GDScript和C#两套业务框架。
- 编辑器小工具也优先使用C#；只有一次性导入脚本允许使用外部脚本语言。

选择原因：

- Godot具有独立2D渲染、物理、TileMapLayer、粒子和动画工具，适合像素沙盒原型。
- C#便于建立强类型物品数据、版本化存档和纯逻辑测试。
- Godot对象与C#之间存在调用成本，因此世界模拟保存在纯C#数据结构中，按批次把变化提交给Godot节点，不在每个方块循环中频繁跨语言边界。

### 世界架构

不能建立三张覆盖全世界的巨型TileMapLayer。推荐结构：

1. WorldModel保存纯C#分块数据。
2. WorldGenerator用同一世界种子生成基础骨架。
3. EraOverlay根据过去、现代、未来和历史节点生成覆盖。
4. ChunkDelta只记录玩家挖掘、放置、线路、容器和NPC变化。
5. ChunkRenderer只为当前时代、玩家附近的分块创建或复用TileMapLayer。
6. 远离玩家的分块不渲染，只进行极低频模拟或完全休眠。

只有当前时代的玩家邻近分块进行完整模拟；非当前时代冻结敌人、物理和计时，只保存节点状态与分块差异。跨时代生态变化只在历史结算时批量生成，避免玩家离开时仍产生不可见结果。

### 存档格式

- 世界存档与角色存档分离。
- 每个存档带schema_version、游戏版本、世界种子和校验值。
- 任何存档结构修改都必须提供迁移函数和旧版本测试样本。
- 容器修改、Boss死亡和历史结算使用事务式日志：先写临时文件，校验成功后替换主存档。
- 禁止GPT在没有人工设计说明和迁移测试时直接修改正式存档格式。

### 单人状态机与结算

- 游戏状态明确分为探索、Boss封锁、穿越引导、历史结算、残响副本和暂停；只有一个状态拥有世界写权限。
- 历史结算期间冻结输入，先写检查点，再在内存计算覆盖，校验后原子提交；中途崩溃只能回到结算前或完整结算后，不能出现半更新世界。
- Boss首杀核心、唯一物品和历史节点使用稳定ID与一次性发放标记，读档或复制世界不能重复触发同一世界的首通奖励。
- 暂停、切出窗口和系统休眠后恢复时重新校验音频、输入焦点与异步存档句柄，避免单人长档损坏。

### 性能预算

- 目标帧率：1080p下稳定60 FPS；最低硬件在垂直切片完成后以真实测试机确定。
- 同屏常规活动敌人目标上限约50只；超出后采用生成限额和远距离休眠。
- 世界生成必须显示可取消进度，标准世界目标在普通SSD上60秒内完成基础骨架。
- 自动存档异步执行；Boss战和历史结算时不触发普通自动存档。
- 目标机器95%帧时间不高于16.7毫秒、99%不高于25毫秒；历史结算允许显示进度，但不能冻结窗口或丢失输入焦点。

### 工程纪律

- Git主分支受保护，两人都通过短分支和代码审查合并。
- 像素图、音频和大型二进制文件使用Git LFS。
- 每次可发布构建自动执行编译、纯逻辑测试、数据表校验和Windows导出。
- 所有物品、敌人、Boss、历史节点和对白使用稳定ID，显示名称可以修改，ID不能随意重命名。
- 用设计决策记录保存引擎升级、存档格式、世界生成和历史结算的重要决定。

## 6.8 两人团队分工

### 成员A：技术与战斗负责人

- 世界分块、存档、历史结算和Steam接入。
- 角色控制器、伤害系统、Boss状态机和性能分析。
- 构建、持续集成、崩溃日志和版本迁移。

### 成员B：内容与视觉负责人

- 像素资产、动画、UI、生态区和关卡地标。
- NPC、物品、掉落表、制作配方和历史状态配置。
- 音频整合、教程、可读性和内容测试。

### 共同职责

- 每周至少一次由非实现者完整游玩最新主线构建的交叉测试。
- Boss设计、战斗手感和范围取舍必须由两人共同批准。
- 任何一人离开一周，另一人仍能构建项目、恢复存档和发布测试版，避免知识只存在一人脑中。

分工是所有权而不是隔离。成员B不应完全不懂存档工具，成员A也不能只写系统而从不制作实际内容。

## 6.9 GPT使用规范

适合交给GPT辅助的内容：

- 有明确输入输出的小型代码模块。
- 单元测试、属性测试、存档迁移测试和数据校验器。
- 编辑器批处理工具、掉落表检查、未使用资源扫描。
- 物品说明、NPC对白和英文翻译初稿。
- Bug复现步骤整理、日志分析和性能假设列表。
- 同一规则下的低风险内容变体草稿。

不能直接交给GPT决定的内容：

- 整体架构、历史结算边界和存档兼容策略。
- Boss手感、数值平衡和美术最终一致性。
- 未经审查的大规模代码重写。
- Steam密钥、签名文件、账号凭据和玩家隐私数据。
- 直接模仿具体在世艺术家的美术、音乐或文本风格。

每个GPT任务必须包含：

1. 目标文件和允许修改的范围。
2. 输入、输出和失败条件。
3. 可运行的验收测试。
4. 不允许改变的接口。
5. 人工审查人。

GPT生成的代码与资产都进入正常审查流程，不能因为“能运行”就直接进入主分支。

### AI内容与Steam披露

- 建立AI内容台账，记录资产名称、工具、提示目的、人工修改、素材来源和最终使用位置。
- 如果AI生成或辅助生成的美术、音频、叙事、翻译等内容最终提供给玩家，按Steam内容调查如实披露。
- 1.0不在游戏运行时连接GPT或其他生成服务，避免内容安全、持续费用、离线可用性和隐私问题。
- 代码辅助与内部效率工具也保留开发记录，但重点审查所有实际随游戏发布、供玩家消费的内容。

## 6.10 存档与世界管理

- 自动存档采用五份轮换备份，并保留最近一次历史结算前检查点；备份带版本、时间、世界ID和校验状态。
- 玩家可以创建带名称的手动备份，但读取备份会复制为新的世界ID，原档保持不变，避免覆盖后无法反悔。
- Steam Cloud只同步已经原子提交的文件；本地与云端都发生变化时保留两份，界面显示游玩时长、版本和最后地点后让玩家选择。
- 删除世界需要长按确认，并先移入游戏内“最近删除”目录；最近三份删除记录可在30天内恢复。
- 历史结算、Boss核心发放、容器写入和大型建筑拆除写入事务日志；异常退出后自动选择最后一个完整提交点。
- 存档界面明确标记版本不兼容、校验失败和只读恢复状态，禁止静默丢弃未知字段后覆盖原档。

## 6.11 测试门槛

进入内容Alpha前必须通过：

- 相同种子重复生成100次，基础地标坐标哈希一致。
- 随机挖掘、放置和历史结算组合至少运行1000轮，不删除玩家标记方块。
- 同一时锚角色无法进入自己已经占据的历史区间；连续回访三个过去窗口100次不产生重复角色或重复首通核心。
- 只有持有有效`causal_anchor_id`的活体、信号、剧情唯一物品和事件快照能进入记录层；普通被观察NPC与城镇在结算后只保留新历史，不产生第二实体。
- 三座装置依次被毁时恰好消耗三层应急锚储备；第四次尝试补偿必须失败，且任何补偿都不能恢复被毁装置或被历史节点记录为永久死亡／失踪的NPC。
- 零时引擎毁灭后批量制作、丢弃、存取和跨时代携带10000件普通物品，`item_instance_id`保持唯一且不申请新的`causal_anchor_id`。
- 删除背包中的主线钥匙和核心凭证、把凭证留在休眠时代或旧版存档中缺失时，世界账本权限仍有效，时间机器只恢复同一物品实例，不重复发放奖励。
- 用实体方块、背景墙、液体和线路分别堵塞每个公共落点后，系统能使用同区域备用平台；不得删除玩家建筑或把玩家送进伤害格。
- 因果矿脉在任一时代枯竭后，另外两个时代的共享ID同步转为残矿；保存、退出和读取备份不能恢复同一世界ID的原矿脉。
- 连续跨时代往返20次不会重复刷新商店、催熟作物或推进剧情日期；达到有效游玩时间后只补算一个生产周期。
- 当前版本存档读写往返后，物品、容器、NPC和历史节点完全一致。
- 至少两个旧版本样本能够迁移到当前存档。
- 连续单人游玩4小时后内存占用不持续增长超过10%，存档可正常读取，世界与角色状态一致。
- 自动化执行100次保存／退出／载入循环，物品、容器、唯一核心、NPC与历史节点哈希完全一致。
- 在历史结算六个步骤、系统休眠和强制结束进程时分别注入中断，恢复后只能得到结算前或完整结算后的世界。
- 第一次穿越中至少80%的新测试玩家能辨认三个相同地标。
- 垂直切片结尾至少80%的新测试玩家能在不看文字攻略时主动使用过去／现代／未来残片通过路线谜题，并能说明未来不是单纯过场。
- 至少80%的垂直切片测试玩家能在错相追猎者战后说出两个时代形态的处理差异；战斗切换不生成第二个精英、重复奖励或清空弹幕。
- 矿镇A／B建设方向在至少24名盲测玩家中不能有一项因明显战力或主线便利优势获得超过75%的选择率；超过时调整功能价值，而不是给冷门方向增加“好人”标签。
- 第三次赫洛恩挑战的胜利来自学习招式，测试中不得出现一套必需的随机稀有掉落。
- 第三次赫洛恩在90秒前、开门后继续战斗和残响重试三种路径中使用同一生命与阶段规则，不回血、不锁血、不重复发放成就。
- 四个受控切换Boss连续各测试50轮，时代切换不复制Boss、弹幕、消耗品、首杀核心或战斗计时。
- 在零时核心生命归零、死亡协议发送完成和引擎摧毁三个提交点分别强制中断，恢复后死亡信号不能缺失、重复发送或在发送前被玩家摧毁；来源哈希始终指向同一起源残响。
- 在最终核心毁灭前对现代赫洛恩触发脚本伤害时必须执行连续体回滚；核心毁灭后新现代状态不再接受未来回滚，也不能重新连接已封存协议。
- Boss战封锁期间放置、挖掘、液体和线路修改全部被拒绝且有明确反馈；战斗结束后恢复，战前建筑与容器哈希不变。
- 枪械与弓箭玩家连续失败Boss十次时，普通弹药返还不产生净增殖，并始终保有一次基础重试量；特殊弹药不被返还。
- 飞行与地面召唤物在100个故意卡墙、深坑、窄道和跨时代场景中不隔墙攻击、不触发因果机关，并能按规则回收复位。
- 通关后的新未来不再生成零时赫洛恩；死亡信号、最终战和成就仍能通过同一来源哈希追溯到起源残响。
- 终局前六种可选节点组合分别完成通关，确认界面显示状态准确；残响补战不能把结果、物品或风貌合并回主世界。
- 在旧未来建设、命名基地并放入100个容器后完成终局，所有实体和库存只在新未来保留一份，起源残响只能查看不可交互投影。
- 沉潮闸门三种水位切换各运行100轮，局部桶装水不改变历史状态，玩家建筑与容器不被水位覆盖事务删除或复制。
- 拆除全部NPC住房后，关键NPC进入公共时锚站，主线、商店和工坊不发生软锁。

进入Steam公开页面前必须有：

- 无概念图冒充的真实游戏截图。
- 一段连续、未预渲染的实际玩法录像。
- 能准确描述当时已有内容的功能列表。
- AI内容台账、素材授权表和临时隐私说明。

## 6.12 六项原型问题的验收规格

以下数值是垂直切片的首轮调试基线，不是未经测试就锁死的正式数值。每项都有通过门槛和失败后的减法方案；不能用“以后再优化”让失败原型直接进入内容铺量。

### 6.12.1 挖掘、移动与近战手感

首轮输入与动作基线：

| 项目 | 原型基线 |
|---|---|
| 土块／软块挖掘 | 新手工具每格0.18—0.25秒 |
| 普通石块挖掘 | 新手工具每格0.35—0.50秒 |
| 同级矿石挖掘 | 每格0.65—0.90秒；硬度门槛块不超过1.20秒 |
| 工具升级收益 | 同类方块用时减少约25%—35%，同时提升可挖等级或范围，而非只加小数值 |
| 基础触及距离 | 无加成时以角色为中心约5格；光标越界时明确显示不可达 |
| 跳跃容错 | 离开边缘后的土狼时间100毫秒；落地前跳跃输入缓冲120毫秒 |
| 快速近战前摇 | 90—160毫秒；命中停顿约25毫秒 |
| 中型近战前摇 | 180—280毫秒；命中停顿约40毫秒 |
| 重型近战前摇 | 350—550毫秒；命中停顿约60毫秒 |

命中停顿只影响命中双方的短暂表现，不冻结环境机关或隐藏延长无敌帧。敌人受击必须同时提供轮廓闪烁、音效、击退或护甲火花，不能只靠飘字确认。

验收测试使用至少12名未接触项目的玩家，每人完成30分钟“挖房间—找矿—击杀—建工作台”流程：

- 至少9人评价基础挖掘“不拖沓”，且没有人因为不知道是否命中而连续空挥三次以上。
- 至少80%的玩家能在8分钟内独立挖出并搭建一个可用的最小房间。
- 录像统计中的已输入但未执行动作低于5%；超过时优先修输入缓冲、动画取消和光标反馈。
- 三种近战重量必须在关闭伤害数字后仍能被玩家分辨。

若未通过，停止新增武器和矿物，先迭代一个敌人、三把武器和三种方块；不能靠提高掉落量掩盖挖掘本身不好玩。

### 6.12.2 时间切换速度

| 切换方式 | 输入与演出预算 | 使用限制 |
|---|---|---|
| 时间薄弱点 | 确认约0.20秒，切换演出0.55—0.75秒，总失控时间不超过0.90秒 | 只能在固定坐标使用 |
| 便携相位针 | 1.50秒可打断引导＋约0.60秒演出 | 仅安全区；过去／现代或返回时锚 |
| 完整相位罗盘 | 方向选择后0.35秒引导＋约0.60秒演出，总计不超过1.10秒 | 战斗封锁区不可用；冷却2.5秒 |

- 相邻时代分块在玩家靠近薄弱点或装备罗盘时后台预取；切换造成的主线程停顿目标低于100毫秒。
- 提供“简化穿越闪光”选项，但不能完全取消空间提示和时代标签。
- 纪元选择界面暂停世界；确认后的引导按表中时间执行，受击会取消且不消耗冷却。
- 路线谜题按每分钟2—4次切换设计，不能要求玩家连续十几次闪屏才能通过一条普通走廊。

最低配置上的90%切换必须在目标时间内完成；外部测试中若超过15%的玩家明知另一时代有路线却因为等待而拒绝切换，先缩短演出和预取数据，再增加切换型谜题。

### 6.12.3 随机世界与地标辨识

生成器先生成不随时代改变的“世界骨架图”，再放置时代覆盖。每个主线跨时代区域至少拥有四个视觉锚点：大型地形轮廓、主要入口、人工地标和独特背景物。

- 山脉、洞穴主干和地标插槽在三个时代使用完全相同的骨架坐标。
- 覆盖层可以封闭或打开支路，但主要入口水平偏移不超过8格、垂直偏移不超过12格；超过时必须保留可见遗迹指向原位置。
- 从出生点到废矿、时间机器、首个Boss房和首个时代出口必须存在至少一条无需越级工具的路径。
- 强制结构冲突时只重投局部地标插槽，最多尝试5次；仍失败则使用人工验证的后备模板，不无限重生整张世界。

自动测试至少覆盖1000个种子，检查地标重叠、必经路径、出生安全区、时代落点和结构边界。人工测试使用至少24名新玩家、12个不同种子：分别探索现代与过去各15分钟后，至少80%的玩家能正确对应4个锚点中的3个，地图落点中位误差不超过30格。失败时增加强制地标和轮廓复用，不能继续增加随机噪声。

### 6.12.4 建筑与历史覆盖冲突

历史结算必须是一笔可回滚事务：

1. 保存世界、角色与容器快照并写入校验值。
2. 在内存中生成新覆盖层，不立即改写正式分块。
3. 用玩家方块掩码和结构边界做冲突检测；玩家实体方块周围保留2格结构缓冲。
4. 道路、门、NPC住处和任务物件优先移动到预设替代插槽。
5. 仍无法解决时保留玩家建筑，把被替代内容放入时间残响，并在地图显示原因。
6. 完成NPC可达性、容器ID和出生点检查后原子提交；任一步骤崩溃都读取结算前快照。

玩家放置方块、共享箱库存和已命名基地实行零丢失容忍。测试需要运行至少10000轮随机建筑／六节点／三时代组合，并制作100个故意堵门、包围NPC、跨地标建家的人工破坏样例；还要在结算六个步骤分别模拟崩溃。出现一次无法恢复的玩家建筑或容器丢失，就不能扩展第三时代。

### 6.12.5 单人终局Boss可读性

- 任意1秒窗口内，同一玩家最多同时面对两个要求不同躲避方向的主机制；隐藏挑战可以短暂达到三个，但必须提前组合预告。
- 同屏高优先级Boss预警不超过3组；持久伤害区域最多覆盖可站立面积的25%。Boss发动大招时，普通召唤物上限为8只或精英4只。
- 玩家召唤物与己方弹幕提供35%—100%不透明度滑杆，默认65%，不遮盖Boss高优先级预警；伤害数字按0.5秒聚合。
- 玩家、Boss、可反弹弹体、致命地面和普通装饰分别使用不同轮廓形状，不能只靠颜色区分。
- 镜头只做有限动态缩放，并提供Boss离屏方向标记；缩放不能让角色像素小到无法读动作。
- Boss连续机制之间必须保留经实测可到达的安全转场；镜头、特效和残影不能改变实际碰撞判定时间。

至少组织12名不同流派玩家完成三轮终局Boss测试。回放问卷中至少80%的死亡者能正确指出致死来源，“完全没看见攻击”的死亡低于15%；目标机器95%帧时间不高于16.7毫秒、99%不高于25毫秒。若失败，优先减少己方弹幕、召唤物和同时机制，不能只把所有预警做得更大更亮。

### 6.12.6 内容人日预算

“1人日”指一名成员约8小时的专注制作时间，包括实现、美术或整合、数据、基础音效、测试与修正，不能只统计写代码时间。

| 内容单位 | 首轮预算 | 超出后的处理 |
|---|---:|---|
| 模板化普通武器 | 0.75—1.5人日 | 复用动作与特效组件，删除纯数值重复品 |
| 独特机制武器 | 2.5—5人日 | 每阶段限制少量招牌武器 |
| 普通敌人基础原型 | 4—7人日 | 合并相似行为，不再新增只换皮敌人 |
| 时代变体 | 1—2.5人日 | 必须改变至少一个行为，不够则只做视觉覆盖 |
| 精英敌人 | 2—4人日 | 从成熟敌人组合机制，不新建整套骨架 |
| 主线Boss | 18—30人日 | 先灰盒验收全部阶段，再进入正式美术 |
| 可选Boss | 12—20人日 | 最先进入削减名单 |
| 最终Boss | 40—60人日 | 单独预留，不从普通Boss平均值挤预算 |
| 功能NPC及状态对白 | 4—8人日 | 共用日程和商店框架，减少组合对白 |
| 一个完整历史节点 | 8—15人日 | 复用覆盖组件，保持最多三种地区状态 |
| 一个生态环境套件 | 30—50人日 | 不含独立Boss；三个时代共享骨架与动画 |

全项目首轮总预算为940—1320人日：核心系统、工具、存档和历史结算约380—520；内容生产约390—560；测试、优化、本地化和发行约170—240。计入沟通、返工、休假和发布空档后，对应两名全职成员约2.4—3.8年，并已经假设大量复用；不因使用GPT把它压缩为一年。

垂直切片结束后，用真实工时重算中位成本。若三类以上内容的中位成本超过表格上限25%，按以下顺序削减：可选Boss 1→0、常规敌人配置48→40、六阶段功能装备约126→110、历史节点6→5，最后才考虑生态区6→5。不得削减首个矿镇闭环、三座过去装置、建筑保护、存档回滚、第三次赫洛恩隐藏挑战和最终Boss。

## 6.13 仍不能由策划案替你决定的事实

以下不是设计空缺，而是两名开发者需要提供的现实条件：

- 两人分别掌握多少编程、像素美术、动画、音频和发行经验。
- 是全职还是业余开发。
- 能用于外包音乐、音效、英文校对、QA、商标和法律工作的预算。
- 是否有两套以上Windows测试机和Steam Deck测试设备。
- 《零时回响》名称是否完成商标与商店重名检索。

如果两人都主要是程序员，必须减少角色动画和生态数量，或为美术外包留预算。如果两人都缺少像素动画或Boss调试经验，应先把垂直切片控制在一个生态区和两名Boss，不得用生成数量掩盖成品质量不足。

# 总体评审

当前方案已经具备一个有辨识度的核心：

**玩家不是在三张地图之间换关卡，而是在同一个随机世界里制造历史，并回来居住在自己改变后的世界中。**

四次赫洛恩遭遇现在能够成立：

- 第一次让玩家知道差距。
- 第二次让玩家理解Boss依靠什么无敌。
- 第三次让高手真实摧毁外层战斗身体，但不冒充已经摧毁本体意识。
- 第四次在移除不公平规则后摧毁零时引擎；死亡信号先发出，旧闭环随后封存为起源残响。

v0.9纸面压力审查已经补齐目前已知的主线因果与软锁缺口：

- 新未来无需再次生成赫洛恩，死亡信号仍能追溯到只读起源残响。
- 三个过去窗口不重叠，同一时锚角色不能遇见或复制自己。
- 普通资源可以分时代采集，终局因果矿脉、核心和容器不能跨时代复制。
- 第三次胜利与第四次决战分别对应战斗身体和连续性核心。
- 岚的性别呈现随建档选择固定，尾声关系由玩家决定且不绑定奖励。
- 单人角色进度绑定世界，旧未来、唯一核心和因果矿脉都不能通过换档或跨世界携带复制。
- 时锚不再由“看见”触发，只有注册`causal_anchor_id`能够保存身份与事件来源；普通物品只依靠`item_instance_id`防复制，残响不能再次影响主世界。
- 剧情日期与昼夜模拟分离，跨时代往返不能刷新商店、催熟作物或错过主线窗口。
- 因果补偿被限制为三层可见储备，不能无限修补剧情。
- 第三战从第一秒可受伤，90秒只开启撤离门；留下后不回血、不锁血。
- 祁安与调查联盟提前铺垫现代赫洛恩的审判和集团瓦解，不在结局凭空出现机构。
- 死亡信号是维持连续体的自动协议；时晶研究与零时计划早于警告存在，Boss不会由一段无来源警告凭空创造。
- 现代赫洛恩在未来核心毁灭前会被连续体回滚，所以玩家必须进入未来摧毁共同意识，而不是忽略一个更简单的现代击杀方案。
- 终局前明确封存未完成节点；通关后残响只补内容，不把选择、建筑或奖励复制回主世界。
- 旧未来玩家基地事务式迁移到新未来，起源残响只显示不可交互投影。
- 主线钥匙与权限写入世界账本，公共落点拥有备用平台，玩家不能通过丢失物品或堵门造成软锁。
- 地牢强化等级、Boss场地冻结、水位离散状态、召唤寻路与弹药返还已有明确边界，不再把沙盒自由留成绕关漏洞。

删除联机消除了房主权威、断线恢复、三时代同步与多人Boss可读性这一整组最高风险。最大的项目风险现在是核心手感、历史覆盖不损坏建筑、长档稳定性和内容规模。正式制作顺序必须是：

1. 先验证挖掘、建造与战斗手感。
2. 再验证过去与现代共享随机地图骨架。
3. 在同一矿井加入6—8分钟可操作未来残片和错相追猎者，验证三时代不是过场宣传或单纯路线换皮。
4. 验证一次历史改写不会破坏玩家建筑，并能把新城镇放到可见的备用插槽。
5. 完成两小时矿区闭环，并让测试玩家主动使用三时代路线谜题。
6. 对保存、退出、崩溃、时锚唯一性和历史结算做破坏性恢复测试。
7. 灰盒验证至少一场受控时代切换Boss，最后才扩展完整内容。

挖掘与近战、切换速度、地标辨识、建筑冲突、单人终局Boss可读性、时锚唯一性和内容人日已经拥有首轮参数与验收线，因此不再是“以后再看”的模糊问题。但策划案只能规定测试方法，不能预先宣布实际手感已经通过。

因此本案可以评价为“当前没有已知的主线级致命矛盾、核心有辨识度、具备优秀作品的潜力”，不能评价为“已经确定是一款优秀游戏”或“未来不会发现任何边界问题”。优秀与否仍取决于挖掘、近战、Boss、切换节奏和历史反馈在真实游玩中是否成立；新发现的存档与因果边界必须继续进入本节同等级测试，而不是靠补一句世界观解释。

如果两小时垂直切片能够让玩家主动返回旧地点、寻找改变并愿意继续建造，能够完成一次三时代路线谜题，六项原型指标达到第6.12节门槛，而且100次存读与历史结算中断测试全部通过，这个项目才拥有支撑完整一周目的核心玩法。当前状态是“允许制作垂直切片”，不是“允许直接生产全部内容”。
