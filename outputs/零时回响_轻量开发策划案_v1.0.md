# 《零时回响》轻量开发策划案 v1.0

> 目标：由两名开发者借助 GPT 制作一款能够完成、能够发布的单人 2D 像素动作游戏，而不是制作另一款《泰拉瑞亚》。

## 一、产品定义

| 项目 | 决定 |
|---|---|
| 类型 | 单人 2D 横版轻沙盒动作冒险 |
| 平台 | Steam / Windows，键鼠优先，手柄作为发布前验收项 |
| 时长 | 主线 3—5 小时，全收集 6—8 小时 |
| 画面 | 16×16 像素地块，角色与 Boss 使用少量关键帧动画 |
| 世界 | 一张半固定地图，过去、现代、未来共享同一地形骨架 |
| 核心卖点 | 玩家在同一地点的三个时代挖掘、战斗并改变历史，随后亲眼看见现代与未来发生变化 |
| 开发方式 | 两人制作；GPT 辅助代码、测试、数据表和文本草稿，所有设计、验收和最终资产由人负责 |
| 明确不做 | 联机、无限世界、完整液体模拟、复杂电路、NPC住房系统、农场、坐骑、职业树、创意工坊、多结局树 |

这不是一款内容量接近《泰拉瑞亚》的游戏，而是一款借用其“挖掘、制作、横版战斗”操作语言的短篇时间旅行游戏。

## 二、必须保留与必须删除

### 必须保留

1. 过去、现代、未来三个时代。
2. 同一地点跨时代可辨认。
3. 三次进入过去并摧毁三座装置。
4. 两次进入未来。
5. 赫洛恩四次直接遭遇：两次剧情压制、一次高难隐藏胜利、一次最终决战。
6. 在过去救下米卡后，现代的废矿变成有人生活的矿镇；米卡只对隐藏身份的主角产生熟悉感。
7. 岚拥有男性与女性版本，功能和剧情完全相同。
8. 玩家基地不会因为历史变化被删除。

### 从原方案删除

1. 六个大型生态区缩减为三个紧凑区域。
2. 十个完整 Boss 缩减为四个完整 Boss、两个精英守卫。
3. 约 126 件装备缩减为 24—30 件功能装备。
4. 48 套敌人配置缩减为 8 种基础敌人和 4 种时代变体。
5. 六个复杂历史节点缩减为三个主线装置和一个米卡救援结果。
6. 完全随机世界改为“固定骨架＋随机矿脉、洞室和战利品”。
7. 全地图永久自由建造改为“基地永久建造＋野外轻量放置”。
8. 通关后只保留 Boss 残响、自由探索和收集，不制作完整世界风貌编辑器。

## 三、故事与角色

### 一句话故事

来自毁灭未来的岚抵达现代，请求主角修复时间机器。主角在未来回声中看见熟悉的矿区被“叠时灾变”吞没，于是三次返回过去摧毁赫洛恩的时间装置，最后进入未来终结维持灾难闭环的零时引擎。

### 主角为什么决定改变未来

开场不是用预言或记录指责玩家。玩家先在现代废矿救出一名商人并修好临时工作台，随后未来回声覆盖同一地点：工作台锈毁、商人的求救广播中断、三个时代的地形开始重叠。玩家由此知道眼前的人和地点会真实消失。

第一次从过去归来后，玩家发现废矿变成小型矿镇，年老的米卡对隐藏身份的主角产生熟悉感。主角的变化通过“开始主动检查其他地区是否还能被拯救”表现，不强迫自定义角色说固定情绪台词。

### 岚

- 岚是从旧未来返回现代的唯一时间旅行者和主要同伴。
- 新建世界时，玩家独立选择男性或女性版本；选择不与主角性别绑定，选定后永久写入该世界存档。
- 两个版本共用任务、能力、奖励与人物关系，不制作两套剧情。
- 岚不是隐藏反派，也不会突然背叛。冲突来自岚担心旧未来被完全抹除，但最终接受把它保存为只读残响。

### 赫洛恩

赫洛恩原本研究时晶，希望证明人的意识可以跨越历史保持连续。他长期承受多条被改写历史的记忆，最终相信“只有唯一、停止变化的时间才是真实”，于是启动零时引擎，把三个时代强行叠加。

未来赫洛恩死亡时会自动向现代的自己发送警告。警告使现代赫洛恩提前追杀主角，却也让主角进入闭环。最终战中警告发送完成后，主角摧毁零时引擎；已经发生的闭环成为只读残响，新未来不再重复生成赫洛恩。

## 四、简单时间规则

玩家只需要理解六条规则：

1. 三个时代共享同一张地图骨架。
2. 只有离开过去时，历史变化才统一结算。
3. 玩家基地处于时锚保护区，不会被历史覆盖。
4. 过去的赫洛恩受到零时引擎补偿，不能被永久杀死，但三座装置可以逐步削弱他。
5. 主角、岚和赫洛恩保留旧历史记忆，普通 NPC 只记得最新历史。
6. 最终信号发送后摧毁零时引擎，旧闭环仍有来源，但不再强迫新未来重复发生。

`causal_anchor_id`、事务日志和唯一物品 ID 只写入技术文档，不在剧情对白中向玩家解释。

## 五、世界结构

### 三个紧凑区域

| 区域 | 现代 | 过去 | 未来 |
|---|---|---|---|
| 灰脊矿区 | 废矿、时间机器、玩家基地 | 繁荣矿镇、时髓采集井 | 坍塌避难所、错相裂缝 |
| 雾林观测站 | 被集团封锁的湿林 | 尚未污染的森林、先见观测阵 | 预测残骸、错相追猎者 |
| 恒日设施 | 停运熔炉与铁路 | 运作中的恒日熔炉 | 零时堡垒与最终核心 |

地图的大型洞穴、山体轮廓和入口固定。每次新游戏只随机以下内容：

- 矿脉位置。
- 小型支洞组合。
- 普通敌人刷新点。
- 非关键宝箱与材料房。

主线建筑、Boss 房、时间落点和跨时代地标不随机，避免生成失败和玩家迷路。

## 六、核心玩法循环

探索与挖掘  
→ 获得材料和固定装备  
→ 制作一项工具或武器升级  
→ 击败 Boss／精英守卫  
→ 解锁新的时代坐标  
→ 摧毁过去装置或救援 NPC  
→ 返回现代观察变化  
→ 使用新道路进入下一区域

每次历史变化必须同时提供三种反馈：

1. 看得见的环境变化。
2. 一个 NPC、商店或路线变化。
3. 一个实际可用的新资源或捷径。

## 七、战斗与装备

### 流派

- 近战为主：快速剑、重刃、长柄武器。
- 远程：两把枪械、两把弓弩。
- 召唤：两种机械无人机。
- 不设置职业和技能树，玩家通过装备切换流派。

### 装备上限

| 类型 | 数量目标 |
|---|---:|
| 近战武器 | 8 |
| 枪械 | 2 |
| 弓弩 | 2 |
| 机械召唤器 | 2 |
| 护甲套装 | 3 套，共 9 件 |
| 工具与时间装置 | 5—7 |
| 总计 | 24—30 件 |

制作只使用三个等级、最多十二种主要材料。普通 Boss 失败后，玩家应当能在三分钟内再次挑战；基础弹药和常用药剂在失败后返还一次最低重试量，防止连续失败变成重新挖矿。

## 八、Boss与四次赫洛恩遭遇

### 完整 Boss

1. **错时掘进机**：现代废矿教学 Boss，奖励第一次正式穿越。
2. **时髓巨虫**：过去矿镇 Boss，守卫时髓采集井。
3. **赫洛恩战斗体**：第三次遭遇的高难战斗身体。
4. **零时赫洛恩**：最终意识核心。

先见观测阵和恒日熔炉各使用一个拥有两至三招的精英守卫，不制作独立多阶段 Boss、专属音乐和大量动画。

### 四次遭遇

| 次数 | 形式 | 规则 |
|---|---|---|
| 第一次 | 现代，约 15 秒剧情压制 | 赫洛恩冻结时间并击倒主角；不显示正常 Boss 血条，不消耗药品，不掉钱 |
| 第二次 | 未来，约 45 秒扫描生存 | 目标是完成扫描而不是击杀；任务完成后遭终末校准击倒，全部资源恢复 |
| 第三次 | 未来外层，完整高难战 | 90 秒后撤离门开启；玩家可撤离推进剧情，也可留下击败战斗体 |
| 第四次 | 零时核心，正常最终战 | 所有攻击都有预警，可以学习和躲避，不读输入、不锁血、不无条件闪避 |

第三次隐藏胜利名为“不在记录中的胜利”。失败或撤离后可以通过残响重试；通关后重试会同步装备等级，不能用终局数值碾压。提前取胜会改变最终 Boss 的裂痕外观、开场对白和一招等价变体，但不让最终战变简单。

## 九、三座过去装置

| 装置 | 摧毁后的实际效果 | 世界变化 |
|---|---|---|
| 时髓采集井 | 最终 Boss 失去无限重构，只保留有限阶段回复 | 米卡获救，现代废矿形成小型矿镇 |
| 先见观测阵 | 赫洛恩不能精确预测玩家，只能使用有前摇的假动作 | 现代湿林污染减轻，开放观测站捷径 |
| 恒日熔炉 | 未来堡垒失去永久护盾，只能使用短时防御 | 未来避难所恢复能源，开放最终核心入口 |

三座装置都必须摧毁，不制作“保留装置让 Boss 更强”的路线。可选救援只改变 NPC、商店、外观和收集内容，不改变最终 Boss 的基础难度。

## 十、建造与历史保护

为了保留建造乐趣但降低技术成本：

- 时间机器周围设置一块约 80×40 格的永久基地保护区。
- 玩家可以在保护区自由放置地块、墙、箱子、工作台和约 30 种家具。
- 野外允许放置火把、绳索、平台和临时方块，但主线地标使用清晰可见的“时间不稳定区”，其中不能永久建造。
- 历史变化只替换预先制作的地标覆盖层，不重写整张地图。
- 结算前自动保存；结算失败直接恢复到结算前存档。

这比“全世界任意建筑都能与所有历史状态自动合并”简单得多，也不会突然删除玩家真正投入时间建造的基地。

## 十一、3—5小时流程

| 时间 | 内容 |
|---|---|
| 0—20 分钟 | 挖掘、建造、救出现代商人、遇见岚；玩家亲手完成一次现代／过去短切换并看到未来回声 |
| 20—50 分钟 | 收集时间机组件，击败错时掘进机，完成第一次正式过去远征 |
| 50—100 分钟 | 过去矿镇、救出米卡、击败时髓巨虫、摧毁第一装置；返回现代观察矿镇变化 |
| 100—170 分钟 | 雾林观测站、第一次赫洛恩剧情压制、摧毁第二装置 |
| 170—230 分钟 | 第一次未来远征，完成扫描并遭遇第二次剧情压制；回到过去摧毁恒日熔炉 |
| 230—300 分钟 | 第二次未来远征、第三次高难遭遇、零时堡垒、最终 Boss 与新未来结局 |

允许自由探索，因此实际通关时间可以在三至五小时之间浮动。

## 十二、开发方案

### 引擎

- 默认使用 Godot 4 稳定版与 GDScript，减少工程配置和语言混用。
- 如果两名成员中有人已经熟练掌握 C#，可以统一使用 C#；一旦选择就不混用两种生产语言。
- Git 从第一天启用；每个可运行版本打标签。

### 0号原型：4—6周

只制作：

- 一个 120×70 格测试矿洞。
- 现代与过去两个覆盖层。
- 挖掘、放置、箱子和存档。
- 三把近战武器、两种敌人。
- 一个灰盒 Boss。
- 一次历史改变和基地保护。

通过条件：

1. 新玩家五分钟内理解挖掘、攻击与建造。
2. 切换时代的失控时间低于一秒。
3. 玩家不看文字也能认出三个相同地标。
4. 历史结算一百次不丢失基地和箱子。
5. 至少三分之二测试玩家愿意继续玩下一段。

不通过就继续修改原型，不制作第二个正式区域。

### 正式制作顺序

1. 0号原型：4—6周。
2. 30—45分钟内部切片：追加4—6周。
3. 完整三至五小时内容：追加4—8个月。
4. 优化、手柄、Steam和外部测试：追加2—3个月。

两名有基础经验的全职开发者，合理目标约8—12个月；业余开发通常需要12—24个月。若希望更快，发布30—60分钟免费序章，不要假装能在几个月内做完大型沙盒。

## 十三、GPT使用规则

GPT适合：

- 角色控制器、状态机和编辑器工具的代码草稿。
- 单元测试、存档往返测试和批量种子测试。
- 装备数据表、掉落表和配方格式检查。
- 临时对白、物品说明和任务流程草稿。
- 崩溃日志分析、代码审查和重复劳动脚本。

GPT不能替代：

- 挖掘与打击手感的真人试玩。
- Boss攻击是否公平的录像检查。
- 像素画风格统一与动画取舍。
- 存档格式设计和迁移责任。
- Steam素材授权、AI内容披露与最终发行检查。

每次让GPT修改代码时，只处理一个明确任务；修改前提交Git，修改后必须运行游戏和测试。禁止一次性要求GPT“把整个游戏做完”。

## 十四、最终评审

原方案最大的不足不是时间逻辑，而是规模：完全随机三时代世界、十个Boss、一百多件装备和全地图建筑保护，会让两人团队多年都无法完成。

轻量版保留了真正有辨识度的部分：

- 同一地点三个时代。
- 过去行动改变现代与未来。
- 四次赫洛恩遭遇。
- 米卡的熟悉感。
- 自定义主角与可选版本的岚。
- 公平的最终Boss与可重试隐藏胜利。

当前结论：**可以开始制作0号原型，但不能直接生产完整游戏。** 如果0号原型证明挖掘、近战、时代切换和第一次历史变化确实好玩，再扩展到三至五小时成品；如果不成立，修改核心而不是增加内容。
